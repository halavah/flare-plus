## 环境准备

### 1. 安装依赖

```bash
cd 06-durable-objects
npm install
```

### 2. 配置 Wrangler

确保 `wrangler.toml` 中的配置正确：

```toml
name = "flare-plus-durable-objects"
main = "src/index.js"
compatibility_date = "2023-12-01"

[[durable_objects.bindings]]
name = "CHAT_ROOM"
class_name = "ChatRoom"

[[durable_objects.bindings]]
name = "COUNTER"
class_name = "Counter"

[[durable_objects.bindings]]
name = "GAME_STATE"
class_name = "GameState"
```

## API 使用示例

### 1. 聊天室 (ChatRoom)

#### 创建聊天室

```bash
curl -X POST http://localhost:8787/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "roomId": "room-123",
    "name": "技术讨论室"
  }'
```

#### 发送消息

```bash
curl -X POST http://localhost:8787/chat/room-123/message \
  -H "Content-Type: application/json" \
  -d '{
    "username": "张三",
    "message": "大家好！"
  }'
```

#### 获取历史消息

```bash
curl http://localhost:8787/chat/room-123/history
```

#### WebSocket 连接

```javascript
const ws = new WebSocket('ws://localhost:8787/chat/room-123/ws');

ws.onopen = () => {
  console.log('已连接到聊天室');

  // 发送消息
  ws.send(JSON.stringify({
    type: 'message',
    username: '张三',
    message: '你好！'
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('收到消息:', data);
};
```

### 2. 计数器 (Counter)

#### 创建计数器

curl -X POST http://localhost:8787/api/counter \

```bash
curl http://localhost:8787/counter/page-views/value
```

```bash

```

### 3. 游戏状态 (GameState)

#### 创建游戏

```bash
curl -X POST http://localhost:8787/api/game \
  -H "Content-Type: application/json" \
  -d '{
    "gameId": "game-456",
    "players": ["player1", "player2", "player3"]
  }'
```

#### 开始游戏

```bash
curl -X POST http://localhost:8787/game/game-456/start \
  -H "Content-Type: application/json" \
  -d '{
    "playerIds": ["player1", "player2", "player3"]
  }'
```

#### 执行游戏动作

```bash
curl -X POST http://localhost:8787/game/game-456/action \
  -H "Content-Type: application/json" \
  -d '{
    "playerId": "player1",
    "action": "score",
    "data": {
      "points": 10
    }
  }'
```

#### 获取游戏状态

```bash
curl http://localhost:8787/game/game-456/state
```

#### WebSocket 连接（实时游戏）

```javascript
const ws = new WebSocket('ws://localhost:8787/game/game-456/ws');

ws.onopen = () => {
  console.log('已连接到游戏');
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);

  switch (data.type) {
    case 'connected':
      console.log('连接成功，游戏状态:', data.gameState);
      break;
    case 'game_started':
      console.log('游戏开始:', data.gameState);
      break;
    case 'score_update':
      console.log('分数更新:', data.scores);
      break;
    case 'game_reset':
      console.log('游戏重置');
      break;
  }
};

// 发送游戏动作
ws.send(JSON.stringify({
  type: 'player_action',
  playerId: 'player1',
  action: 'score',
  data: { points: 5 }
}));
```

## 前端集成示例

### React 聊天室组件

```jsx
import { useState, useEffect, useRef } from 'react';

function ChatRoom({ roomId, username }) {
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  const ws = useRef(null);

  useEffect(() => {
    // 连接 WebSocket
    ws.current = new WebSocket(`ws://localhost:8787/chat/${roomId}/ws`);

    ws.current.onmessage = (event) => {
      const data = JSON.parse(event.data);

      if (data.type === 'message') {
        setMessages(prev => [...prev, data]);
      } else if (data.type === 'history') {
        setMessages(data.messages);
      }
    };

    return () => {
      ws.current?.close();
    };
  }, [roomId]);

  const sendMessage = () => {
    if (!input.trim()) return;

    ws.current.send(JSON.stringify({
      type: 'message',
      username,
      message: input
    }));

    setInput('');
  };

  return (
    <div className="chat-room">
      <div className="messages">
        {messages.map((msg, i) => (
          <div key={i} className="message">
            <strong>{msg.username}:</strong> {msg.message}
          </div>
        ))}
      </div>
      <div className="input-area">
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyPress={(e) => e.key === 'Enter' && sendMessage()}
          placeholder="输入消息..."
        />
        <button onClick={sendMessage}>发送</button>
      </div>
    </div>
  );
}
```

## 常见问题

### 1. Durable Objects 是什么？

Durable Objects 是 Cloudflare 提供的强一致性、低延迟的状态管理服务，每个对象实例在全球范围内是唯一的，适合需要协调和实时通信的场景。

### 2. 如何保证数据持久化？

Durable Objects 使用内置的 `state.storage` API 自动持久化数据到 Cloudflare 的分布式存储系统。

### 3. WebSocket 连接限制？

单个 Durable Object 可以处理数千个并发 WebSocket 连接，具体限制取决于您的 Cloudflare 计划。

### 4. 如何处理对象迁移？

使用 `wrangler.toml` 中的 `migrations` 配置来管理 Durable Objects 的版本和迁移。
