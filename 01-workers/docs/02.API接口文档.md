# Cloudflare Workers API 文档

## 概述

Flare Plus Workers API 是一个基于 Cloudflare Workers 构建的高性能边缘 API 服务，提供用户认证、管理、工具函数等功能。

## 基础信息

- **Base URL**: `https://your-worker.your-subdomain.workers.dev`
- **API 版本**: v1.0.0
- **认证方式**: Bearer Token (JWT)

## 认证

所有需要认证的 API 都需要在请求头中包含有效的 JWT Token：

```http
Authorization: Bearer <your-jwt-token>
```

### 获取 Token

通过登录或注册接口获取 JWT Token。

## 错误响应

所有错误响应都遵循统一的格式：

```json
{
  "error": "Error Type",
  "message": "详细错误信息",
  "code": "ERROR_CODE",
  "details": "额外错误详情（可选）"
}
```

### 常见错误码

| HTTP 状态码 | 错误类型 | 说明 |
|------------|---------|------|
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证或 Token 无效 |
| 403 | Forbidden | 权限不足 |
| 404 | Not Found | 资源不存在 |
| 405 | Method Not Allowed | 请求方法不被允许 |
| 409 | Conflict | 资源冲突（如邮箱已存在） |
| 429 | Too Many Requests | 请求过于频繁 |
| 500 | Internal Server Error | 服务器内部错误 |

## 限流

API 实施了请求频率限制：

- **认证接口**: 每分钟 5 次
- **写入接口** (POST/PUT/DELETE): 每分钟 30 次
- **读取接口** (GET): 每分钟 100 次

超过限制时返回 429 状态码。

## CORS

API 支持 CORS 跨域请求，允许的配置：

- **允许的源**: `*`（生产环境建议配置具体域名）
- **允许的方法**: `GET, POST, PUT, DELETE, PATCH, OPTIONS`
- **允许的头**: `Content-Type, Authorization, X-Requested-With, X-CSRFToken`

## SDK 使用示例

### JavaScript/TypeScript

```javascript
// API 客户端类
class FlarePlusAPI {
  constructor(baseURL, token = null) {
    this.baseURL = baseURL;
    this.token = token;
  }

  // 设置认证 token
  setToken(token) {
    this.token = token;
  }

  // 通用请求方法
  async request(endpoint, options = {}) {
    const url = `${this.baseURL}${endpoint}`;
    const headers = {
      'Content-Type': 'application/json',
      ...options.headers
    };

    if (this.token) {
      headers['Authorization'] = `Bearer ${this.token}`;
    }

    const response = await fetch(url, {
      ...options,
      headers
    });

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }

    return response.json();
  }

  // 认证方法
  async login(email, password) {
    const data = await this.request('/api/auth/login', {
      method: 'POST',
      body: JSON.stringify({ email, password })
    });
    this.setToken(data.data.token);
    return data;
  }

  // 工具方法
  async getHash(data, algorithm = 'SHA-256') {
    return this.request('/api/utils/hash', {
      method: 'POST',
      body: JSON.stringify({ data, algorithm, output: 'hex' })
    });
  }
}

// 使用示例
const api = new FlarePlusAPI('https://your-worker.workers.dev');

// 登录
await api.login('demo@example.com', 'demo123');

// 生成哈希
const hashResult = await api.getHash('Hello World');
console.log(hashResult.data.hash);
```
