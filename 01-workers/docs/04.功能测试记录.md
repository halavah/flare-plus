01-Workers 是基于 Cloudflare Workers 构建的高性能边缘 API 服务，运行在 `http://localhost:8787`。

#### API 文档生成
- **端点**: `GET /api/docs`
- **状态**: ✅ 正常响应
- **功能**: 自动生成所有可用 API 端点的详细文档

### 2. ✅ 认证系统

#### JWT Token 机制
- **登录功能**: `POST /api/auth/login`
- **注册功能**: `POST /api/auth/register`
- **Token 验证**: `POST /api/auth/verify`
- **Token 刷新**: `POST /api/auth/refresh`
- **登出功能**: `POST /api/auth/logout`

#### 演示账户
- 邮箱: `demo@example.com`
- 密码: `demo123`
- 状态: ✅ 可正常登录和获取 Token

#### 认证流程
1. 用户提交邮箱密码 → 服务器验证
2. 生成 JWT Token (HMAC-SHA256 签名)
3. Token 存储到 KV，设置 24 小时过期
4. 返回 Token 和用户信息

### 3. ✅ 用户管理系统

#### CRUD 操作
- **用户列表**: `GET /api/users` (支持分页、搜索)
- **用户详情**: `GET /api/users/:id`
- **用户资料**: `GET /api/users/profile`
- **创建用户**: `POST /api/users`
- **更新用户**: `PUT/PATCH /api/users/:id`
- **删除用户**: `DELETE /api/users/:id`

#### 权限控制
- **认证要求**: 所有用户相关接口需要 Bearer Token
- **中间件**: 自动验证 Token 有效性和权限
- **安全检查**: 用户只能访问自己的资料

### 4. ✅ 工具 API 集合

#### 时间服务
- **端点**: `GET /api/utils/time`
- **功能**: 提供服务器时间
- **格式支持**: ISO、Unix 时间戳、毫秒数
- **时区支持**: UTC (可扩展)
- **状态**: ✅ 正常响应

#### 哈希生成器
- **端点**: `POST /api/utils/hash`
- **算法支持**: SHA-1、SHA-256、SHA-384、SHA-512
- **输出格式**: Hex、Base64
- **功能**: 对输入数据生成指定算法的哈希值
- **状态**: ✅ 算法正常工作

#### IP 信息查询
- **端点**: `GET /api/utils/ip`
- **功能**: 获取客户端 IP 地址和地理位置
- **数据源**: CF-Connecting-IP、X-Forwarded-For 等头
- **信息内容**: IP、国家、城市、时区
- **状态**: ✅ 能正常获取 IP 信息

#### Base64 编解码
- **端点**: `POST /api/utils/base64`
- **功能**: Base64 编码和解码
- **支持类型**: 字符串、JSON 对象
- **操作**: encode/decode
- **状态**: ✅ 编解码功能正常

#### UUID 生成器
- **端点**: `GET /api/utils/uuid`
- **功能**: 生成符合 RFC 4122 的 UUID
- **版本支持**: UUID v4
- **批量生成**: 支持指定数量 (最多 100 个)
- **状态**: ✅ UUID 生成正常

#### JSON 验证和格式化
- **验证端点**: `POST /api/utils/validate-json`
- **格式化端点**: `POST /api/utils/format-json`
- **功能**: 验证 JSON 格式、格式化输出、压缩输出
- **状态**: ✅ JSON 处理功能正常

### 5. ✅ 中间件系统

#### CORS 中间件
- **功能**: 处理跨域请求
- **预检请求**: 正确处理 OPTIONS 请求
- **源验证**: 支持通配符域名匹配
- **响应头**: 完整的 CORS 头设置
- **状态**: ✅ 浏览器可正常跨域访问

#### 认证中间件
- **功能**: JWT Token 验证
- **Token 检查**: 验证 Token 格式和签名
- **过期验证**: 检查 Token 是否过期
- **会话检查**: 查询 KV 验证会话有效性
- **黑名单**: 支持 Token 撤销功能
- **状态**: ✅ 认证保护正常工作

#### 限流中间件
- **算法支持**: 固定窗口、滑动窗口、令牌桶
- **限流维度**: IP 地址、用户 ID
- **不同策略**: 认证 API (5/分钟)、写入 API (30/分钟)、读取 API (100/分钟)
- **状态**: ✅ 限流机制正常工作

### 6. ✅ 错误处理

#### 统一错误格式
```json
{
  "error": "Error Type",
  "message": "详细错误信息",
  "code": "ERROR_CODE",
  "details": "额外错误详情（可选）"
}
```

#### 支持的错误码
- **400 Bad Request**: 参数错误
- **401 Unauthorized**: 认证失败
- **403 Forbidden**: 权限不足
- **404 Not Found**: 资源不存在
- **405 Method Not Allowed**: 方法不支持
- **409 Conflict**: 资源冲突
- **429 Too Many Requests**: 请求过于频繁
- **500 Internal Server Error**: 服务器内部错误

### 7. ✅ 安全特性

#### 密码安全
- **哈希算法**: SHA-256
- **加密存储**: 密码不以明文存储
- **演示安全**: 演示账户使用预定义哈希

#### JWT 安全
- **签名算法**: HMAC-SHA256
- **密钥管理**: 使用环境变量 COOKIES_SECRET
- **过期机制**: Token 自动过期
- **恒定时间**: 防止时序攻击

#### 输入验证
- **邮箱格式**: 正则表达式验证
- **必填字段**: 检查必需参数
- **数据清理**: 防止注入攻击
- **类型检查**: 确保数据类型正确
