# 01-Workers 项目概览

## 📋 项目概述

01-Workers 是基于 Cloudflare Workers 构建的高性能边缘 API 服务，展示了完整的 Workers 开发最佳实践。项目采用模块化架构，包含认证、用户管理、工具函数等核心功能。

## 🏗️ 架构设计

### 核心架构
- **入口层**: `src/index.js` - 统一请求处理和路由分发
- **API 层**: `src/api/` - 按功能模块划分的 API 处理器
- **中间件层**: `src/middleware/` - 通用功能（CORS、认证、限流）
- **配置层**: `src/config/` - 环境变量和配置管理

### 技术栈
- **运行时**: Cloudflare Workers (V8 引擎)
- **语言**: JavaScript ES2022
- **认证**: JWT (JSON Web Tokens)
- **存储**: D1 (SQLite)、KV (键值存储)
- **测试**: Vitest
- **部署**: Wrangler CLI

## 🚀 核心功能实现

### 1. 请求处理流程

```mermaid
graph TD
    A[HTTP 请求] --> B[CORS 中间件]
    B --> C[限流中间件]
    C --> D[路由分发]
    D --> E{API 类型}
    E -->|Auth| F[认证处理]
    E -->|Users| G[用户管理]
    E -->|Utils| H[工具函数]
    E -->|Health| I[健康检查]
    F --> J[响应处理]
    G --> J
    H --> J
    I --> J
    J --> K[返回响应]
```

### 2. 认证系统

- **JWT 实现**: 使用 Web Crypto API 生成和验证签名
- **会话管理**: KV 存储会话信息，支持过期时间
- **安全特性**: 密码哈希、Token 黑名单、恒定时间比较

### 3. 限流策略

- **固定窗口**: 基于时间窗口的简单限流
- **滑动窗口**: 更精确的限流控制
- **令牌桶**: 平滑的请求速率控制

### 4. 错误处理

- **统一错误格式**: JSON 格式的错误响应
- **错误分类**: HTTP 状态码与错误类型对应
- **日志记录**: 结构化的错误日志


## 🔒 安全特性

### 认证安全
- **JWT 加密**: HMAC-SHA256 签名
- **Token 过期**: 可配置的过期时间
- **会话管理**: 安全的会话存储

### 数据安全
- **输入验证**: 严格的参数验证
- **SQL 注入防护**: 参数化查询
- **XSS 防护**: 输出转义

### 网络安全
- **HTTPS 强制**: 自动 SSL/TLS
- **CORS 控制**: 精确的跨域配置
- **请求限流**: 防止 DDoS 攻击
