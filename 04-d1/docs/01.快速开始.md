# D1 数据库 - 快速开始

## 📋 项目简介

**04-d1** 是 Cloudflare D1 (SQLite) 数据库的完整 API 实现，提供边缘计算环境下的关系型数据库服务。

### 核心特性

- ✅ 用户管理 CRUD
- ✅ 文章管理 CRUD
- ✅ 自定义 SQL 查询
- ✅ 事务处理
- ✅ 批量操作
- ✅ 数据库迁移
- ✅ 统计分析

## 环境准备

### 1. 安装依赖

```bash
cd 04-d1
npm install
```

### 2. 创建 D1 数据库

```bash
# 创建数据库
wrangler d1 create flare-plus-db

# 记录返回的 database_id，更新到 wrangler.toml
```

### 3. 运行数据库迁移

```bash
# 本地环境
npm run db:local

# 生产环境
npm run db:migrate
```

## 本地开发

```bash
npm run dev
```

服务在 `http://localhost:8787` 启动。

## API 使用示例

### 1. 用户管理

#### 创建用户

```bash
curl -X POST http://localhost:8787/api/users \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "name": "张三",
    "age": 25
  }'
```

#### 获取所有用户

```bash
curl http://localhost:8787/api/users
```

#### 获取单个用户

```bash
curl http://localhost:8787/api/users/1
```

#### 更新用户

```bash
curl -X PUT http://localhost:8787/api/users/1 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "李四",
    "age": 26
  }'
```

#### 删除用户

```bash
curl -X DELETE http://localhost:8787/api/users/1
```

### 2. 文章管理

#### 创建文章

```bash
curl -X POST http://localhost:8787/api/articles \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Hello D1",
    "content": "这是我的第一篇文章",
    "author_id": 1
  }'
```

#### 获取所有文章

```bash
curl http://localhost:8787/api/articles
```

#### 获取用户的文章

```bash
curl http://localhost:8787/api/articles?author_id=1
```

### 3. 自定义查询

```bash
curl -X POST http://localhost:8787/api/query \
  -H "Content-Type: application/json" \
  -d '{
    "sql": "SELECT u.name, COUNT(a.id) as article_count FROM users u LEFT JOIN articles a ON u.id = a.author_id GROUP BY u.id",
    "params": []
  }'
```

### 4. 事务处理

```bash
curl -X POST http://localhost:8787/api/transaction \
  -H "Content-Type: application/json" \
  -d '{
    "queries": [
      {
        "sql": "INSERT INTO users (email, name) VALUES (?, ?)",
        "params": ["user1@example.com", "用户1"]
      },
      {
        "sql": "INSERT INTO articles (title, content, author_id) VALUES (?, ?, ?)",
        "params": ["文章1", "内容1", 1]
      }
    ]
  }'
```

### 5. 批量操作

```bash
curl -X POST http://localhost:8787/api/batch \
  -H "Content-Type: application/json" \
  -d '{
    "statements": [
      {
        "sql": "INSERT INTO users (email, name) VALUES (?, ?)",
        "params": ["user1@example.com", "用户1"]
      },
      {
        "sql": "INSERT INTO users (email, name) VALUES (?, ?)",
        "params": ["user2@example.com", "用户2"]
      }
    ]
  }'
```

### 6. 统计信息

```bash
curl http://localhost:8787/api/stats
```

## 前端集成示例

### React 用户列表

```jsx
import { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchUsers();
  }, []);

  const fetchUsers = async () => {
    try {
      const response = await fetch('http://localhost:8787/api/users');
      const data = await response.json();
      setUsers(data.users || []);
    } catch (error) {
      console.error('获取用户失败:', error);
    } finally {
      setLoading(false);
    }
  };

  const createUser = async (userData) => {
    const response = await fetch('http://localhost:8787/api/users', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(userData)
    });

    if (response.ok) {
      fetchUsers(); // 刷新列表
    }
  };

  if (loading) return <div>加载中...</div>;

  return (
    <div>
      <h2>用户列表</h2>
      <ul>
        {users.map(user => (
          <li key={user.id}>
            {user.name} ({user.email})
          </li>
        ))}
      </ul>
    </div>
  );
}
```

## 数据库最佳实践

### 1. 使用参数化查询

```javascript
// ✅ 好 - 使用参数化查询
await env.DB.prepare('SELECT * FROM users WHERE email = ?')
  .bind(email)
  .all();

// ❌ 差 - 字符串拼接（SQL 注入风险）
await env.DB.prepare(`SELECT * FROM users WHERE email = '${email}'`).all();
```

### 2. 使用事务处理批量操作

```javascript
await env.DB.batch([
  env.DB.prepare('INSERT INTO users...').bind(...),
  env.DB.prepare('INSERT INTO users...').bind(...),
]);
```

### 3. 添加索引优化查询

```sql
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_articles_author ON articles(author_id);
```

## 常见问题

### 1. D1 与传统数据库有什么区别？

- **边缘计算**：运行在全球边缘节点
- **SQLite 兼容**：标准 SQL 语法
- **自动扩展**：无需管理服务器
- **低延迟**：靠近用户

### 2. 免费额度

- 数据库：5 个
- 存储：5 GB
- 读取：500 万次/天
- 写入：10 万次/天

### 3. 数据备份

D1 自动备份，可通过 API 导出数据。
