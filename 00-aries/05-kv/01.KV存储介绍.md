# KV 存储介绍

## KV 概述

Cloudflare KV 是一个全球分布的键值存储系统，构建在 Cloudflare 全球网络边缘，提供极低的延迟访问速度和高可用性。KV 存储特别适合存储配置、会话、缓存等需要快速访问的数据。

## 核心特性

### 1. 全球分布
```javascript
// 数据自动复制到全球边缘节点
- 超过 285 个城市的数据中心
- 数据存储在离用户最近的位置
- 智能路由确保最低延迟
- 自动故障转移和负载均衡

// 地理分布示例
用户请求 → 最近的边缘节点 → KV 读取
纽约用户 → 纽约边缘节点 → 1-2ms 响应
东京用户 → 东京边缘节点 → 1-2ms 响应
```

### 2. 无限扩展
```javascript
// 自动扩展特性

✅ 无冷启动问题

// 容量指标

```

### 3. 强一致性模型
```javascript

```

## 操作模式

### 1. 写操作
```javascript
// 基本写入
await env.MY_KV.put('key', 'value');

// 带选项的写入
await env.MY_KV.put('key', 'value', {
  expiration: 3600,          // 1小时后过期
  expirationTtl: 3600,       // 相对过期时间
  metadata: {
    author: 'system',
    version: '1.0'
  }
});

// 条件写入（使用 ETag）
const { value, metadata } = await env.MY_KV.getWithMetadata('key');
if (metadata.etag === 'expected-etag') {
  await env.MY_KV.put('key', 'new-value');
}

// 批量写入（在 KV 中不支持，需要并行执行）
const writes = [
  env.MY_KV.put('key1', 'value1'),
  env.MY_KV.put('key2', 'value2'),
  env.MY_KV.put('key3', 'value3')
];
await Promise.all(writes);
```

### 2. 读操作
```javascript
// 基本读取
const value = await env.MY_KV.get('key');

// 带类型转换的读取
const value = await env.MY_KV.get('key', 'json');
const value = await env.MY_KV.get('key', 'text');
const value = await env.MY_KV.get('key', 'arrayBuffer');
const value = await env.MY_KV.get('key', 'stream');

// 读取元数据
const { value, metadata } = await env.MY_KV.getWithMetadata('key');

// 批量读取
const keys = ['key1', 'key2', 'key3'];
const values = await env.MY_KV.get(keys);

// 列出键
const list = await env.MY_KV.list({
  limit: 100,
  prefix: 'user:',
  cursor: 'next-cursor'
});
```

### 3. 删除操作
```javascript
// 删除单个键
await env.MY_KV.delete('key');

// 批量删除
const deletes = ['key1', 'key2', 'key3'].map(key =>
  env.MY_KV.delete(key)
);
await Promise.all(deletes);

// 使用 list 和 delete 删除前缀下的所有键
let cursor;
do {
  const list = await env.MY_KV.list({
    prefix: 'temp:',
    cursor,
    limit: 1000
  });

  await Promise.all(list.keys.map(key => env.MY_KV.delete(key.name)));
  cursor = list.cursor;
} while (cursor);
```

// Stale-While-Revalidate
async function getWithSWR(env, key) {
  // 先返回可能过期的数据
  const stale = await env.MY_KV.get(key, {
    type: 'json',
    cacheTtl: 86400  // 允许使用1天的过期数据

  // 后台更新
  env.waitUntil(refreshKey(env, key));

  return stale;
}

async function refreshKey(env, key) {
  const freshValue = await fetchFromSource(key);
  await env.MY_KV.put(key, freshValue);
}

## 数据一致性

### 1. 强一致性
```javascript
// 写后读一致性
async function writeAndRead(env, key, value) {
  // 写入
  await env.MY_KV.put(key, value);

  // 立即读取（保证读取到最新值）
  const readValue = await env.MY_KV.get(key);

  return readValue === value;
}

// 乐观并发控制
async function updateWithCAS(env, key, updateFn) {
  const { value, metadata } = await env.MY_KV.getWithMetadata(key);

  if (!value) {
    // 键不存在，直接创建
    await env.MY_KV.put(key, updateFn(null));
    return { created: true };
  }

  // 应用更新
  const newValue = updateFn(value);

  // 条件更新（模拟 CAS）
  const { metadata: newMeta } = await env.MY_KV.put(key, newValue);

  return { updated: true, oldValue: value };
}
```

### 2. 事务操作
```javascript
// 模拟事务（通过原子操作）
async function atomicTransfer(env, fromKey, toKey, amount) {
  // 原子读取
  const [fromValue, toValue] = await Promise.all([
    env.MY_KV.get(fromKey, 'json'),
    env.MY_KV.get(toKey, 'json')
  ]);

  // 检查余额
  if (!fromValue || fromValue.balance < amount) {
    throw new Error('Insufficient funds');
  }

  // 原子写入
  const fromBalance = fromValue.balance - amount;
  const toBalance = (toValue?.balance || 0) + amount;

  await Promise.all([
    env.MY_KV.put(fromKey, {
      ...fromValue,
      balance: fromBalance
    }),
    env.MY_KV.put(toKey, {
      ...toValue,
      balance: toBalance
    })
  ]);

  return { success: true, fromBalance, toBalance };
}
```

// KV 统计信息
export async function getKVStats(env) {
  const stats = {
    totalKeys: 0,
    totalSize: 0,
    keysByPrefix: {}
  };

  // 统计不同前缀的键数量
  const prefixes = ['user:', 'cache:', 'session:', 'config:'];

  for (const prefix of prefixes) {
    let cursor;
    let count = 0;

  const { value, metadata } = await env.MY_KV.getWithMetadata(key);

### 3. 批量操作
```javascript
// 高效的批量操作
class KVBatch {
  constructor(kv, batchSize = 100) {
    this.kv = kv;
    this.batchSize = batchSize;
    this.operations = [];
  }

  put(key, value, options = {}) {
    this.operations.push(['put', key, value, options]);
    return this.flushIfNeeded();
  }

  delete(key) {
    this.operations.push(['delete', key]);
    return this.flushIfNeeded();
  }

  async flush() {
    const promises = this.operations.map(([type, key, value, options]) => {
      if (type === 'put') {
        return this.kv.put(key, value, options);
      } else {
        return this.kv.delete(key);
      }
    });

    const results = await Promise.all(promises);
    this.operations = [];
    return results;
  }

  async flushIfNeeded() {
    if (this.operations.length >= this.batchSize) {
      return this.flush();
    }
  }
}
```

## 使用场景

### 1. 用户会话
```javascript
// 会话管理
export class SessionManager {
  constructor(kv) {
    this.kv = kv;
  }

  async createSession(userId, userData) {
    const sessionId = crypto.randomUUID();
    const sessionData = {
      userId,
      ...userData,
      createdAt: Date.now()
    };

    await this.kv.put(`session:${sessionId}`, JSON.stringify(sessionData), {
      expirationTtl: 24 * 3600 // 24小时
    });

    return sessionId;
  }

  async getSession(sessionId) {
    const session = await this.kv.get(`session:${sessionId}`);
    return session ? JSON.parse(session) : null;
  }

  async updateSession(sessionId, updates) {
    const session = await this.getSession(sessionId);
    if (!session) return null;

    const updatedSession = { ...session, ...updates };
    await this.kv.put(`session:${sessionId}`, JSON.stringify(updatedSession));
    return updatedSession;
  }

  async deleteSession(sessionId) {
    await this.kv.delete(`session:${sessionId}`);
  }
}
```

### 2. 配置管理
```javascript
// 配置系统
export class ConfigManager {
  constructor(kv) {
    this.kv = kv;
    this.cache = new Map();
    this.cacheTimeout = 300000; // 5分钟
  }

  async getConfig(key, environment = 'production') {
    const cacheKey = `${environment}:${key}`;

    // 检查缓存
    const cached = this.cache.get(cacheKey);
    if (cached && Date.now() - cached.timestamp < this.cacheTimeout) {
      return cached.value;
    }

    // 从 KV 读取
    const config = await this.kv.get(`config:${environment}:${key}`, 'json');

    // 更新缓存
    this.cache.set(cacheKey, {
      value: config,
      timestamp: Date.now()
    });

    return config;
  }

  async setConfig(key, value, environment = 'production') {
    const kvKey = `config:${environment}:${key}`;
    await this.kv.put(kvKey, JSON.stringify(value));

    // 清除缓存
    this.cache.delete(`${environment}:${key}`);
  }
}
```
