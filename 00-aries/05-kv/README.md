## 服务概述

Cloudflare KV 是全球分布式键值存储系统，为边缘应用提供超低延迟的数据访问。

### 免费额度
- 存储：1GB
- 读取操作：每天 100,000 次
- 写入操作：每天 1,000 次
- 列表操作：每天 1,000 次
- 键数量：无限
- 值大小：最大 25MB
- 键长度：最大 512 字节

### 特性说明
- **最终一致性** - 写入后全球同步需要时间
- **自动缓存** - 热点数据自动缓存到边缘
- **TTL支持** - 可设置过期时间
- **批量操作** - 支持一次读写多个键值
- **区域优化** - 根据用户位置自动路由

### 适用场景
- 配置文件存储
- API响应缓存
- 会话数据
- 用户偏好
- 静态资源元数据
- 地理位置数据
