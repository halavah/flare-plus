## 服务概述

Cloudflare Webhooks 允许你接收来自Cloudflare服务的实时事件通知，构建自动化工作流。

### 免费额度
- Webhook调用：每天 100 次
- 事件类型：支持所有服务事件
- 并发连接：最大 10 个
- 超时时间：10秒
- 重试次数：最多 3 次
- 保留时间：事件保留 24小时

### 支持的事件源
- **Zone Events** - 域名配置变更
- **Load Balancer** - 负载均衡状态
- **Workers** - Workers部署、错误
- **Pages** - 部署状态
- **R2** - 存储操作事件
- **D1** - 数据库事件
- **Email Routing** - 邮件事件
- **Account** - 账户级别事件

### 事件特性
- **实时推送** - 事件发生后立即通知
- **结构化数据** - 标准JSON格式
- **安全签名** - 防止伪造请求
- **自动重试** - 失败后自动重试
- **事件筛选** - 可选择接收特定类型事件
