## 服务概述

Cloudflare Durable Objects 提供了全局一致、低延迟的有状态计算能力，每个对象都有唯一的ID和持久化存储。

### 免费额度
- WebSocket连接：每天 20,000 个
- CPU时间：每天 30,000 GB-秒
- 内存：每天 30,000 GB-秒
- 对象数量：无限
- 存储空间：128MB（每个对象）
- 并发连接：每个对象无限制

### 核心特性
- **强一致性** - 全局唯一标识符保证一致性
- **持久化** - 状态自动持久化
- **实时通信** - 原生WebSocket支持
- **全球访问** - 可从任何边缘节点访问
- **事务性** - 支持ACID操作
