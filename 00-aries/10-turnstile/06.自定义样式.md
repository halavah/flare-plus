# Cloudflare Turnstile 自定义样式

## 样式自定义概述

Cloudflare Turnstile 提供了灵活的样式自定义选项，允许开发者将验证组件无缝集成到网站的设计中。

## 内置主题

### 1. Light 主题（浅色）
```html
<div class="cf-turnstile"
     data-sitekey="YOUR_SITE_KEY"
     data-theme="light">
</div>
```
- 默认的浅色主题
- 适合浅色背景的网站
- 高对比度，易于阅读

### 2. Dark 主题（深色）
```html
<div class="cf-turnstile"
     data-sitekey="YOUR_SITE_KEY"
     data-theme="dark">
</div>
```
- 深色主题
- 适合深色背景的网站
- 减少眼部疲劳

### 3. Auto 主题（自动）
```html
<div class="cf-turnstile"
     data-sitekey="YOUR_SITE_KEY"
     data-theme="auto">
</div>
```
- 根据系统主题自动切换
- 支持 `prefers-color-scheme`
- 提供最佳用户体验

### 2. 动态主题切换

```javascript
// 主题管理器
class TurnstileThemeManager {
  constructor() {
    this.themes = {
      light: {
        name: 'light',
        css: 'turnstile-theme-light'
      },
      dark: {
        name: 'dark',
        css: 'turnstile-theme-dark'
      },
      auto: {
        name: 'auto',
        css: 'turnstile-theme-auto'
      },
      custom: {
        name: 'custom',
        css: 'turnstile-custom'
      }
    };

    this.currentTheme = this.detectTheme();
    this.applyTheme(this.currentTheme);
  }

  // 检测系统主题
  detectTheme() {
    const stored = localStorage.getItem('turnstile-theme');
    if (stored && this.themes[stored]) {
      return stored;
    }

    if (window.matchMedia &&
        window.matchMedia('(prefers-color-scheme: dark)').matches) {
      return 'dark';
    }

    return 'light';
  }

  // 应用主题
  applyTheme(themeName) {
    const theme = this.themes[themeName];
    if (!theme) return;

    // 移除所有主题类
    Object.values(this.themes).forEach(t => {
      document.body.classList.remove(t.css);
    });

    // 添加新主题类
    document.body.classList.add(theme.css);
    this.currentTheme = themeName;

    // 保存到本地存储
    localStorage.setItem('turnstile-theme', themeName);
  }

  // 切换主题
  toggle() {
    const themes = Object.keys(this.themes);
    const currentIndex = themes.indexOf(this.currentTheme);
    const nextIndex = (currentIndex + 1) % themes.length;
    const nextTheme = themes[nextIndex];

    this.applyTheme(nextTheme);
  }

  // 监听系统主题变化
  watchSystemTheme() {
    if (window.matchMedia) {
      const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)');
      mediaQuery.addEventListener('change', (e) => {
        if (this.currentTheme === 'auto') {
          this.applyTheme('auto');
        }
      });
    }
  }
}

// 初始化主题管理器
const themeManager = new TurnstileThemeManager();
themeManager.watchSystemTheme();

// 主题切换按钮
document.getElementById('theme-toggle')?.addEventListener('click', () => {
  themeManager.toggle();
});
```

### 2. 键盘导航

```javascript
// 增强键盘导航
class TurnstileAccessibility {
  constructor(container) {
    this.container = container;
    this.addKeyboardSupport();
  }

  addKeyboardSupport() {
    const widget = this.container.querySelector('.cf-turnstile');

    // 添加键盘事件
    widget.addEventListener('keydown', (e) => {
      switch (e.key) {
        case 'Enter':
        case ' ':
          e.preventDefault();
          this.activateVerification();
          break;
        case 'Escape':
          e.preventDefault();
          this.cancelVerification();
          break;
      }
    });

    // 添加焦点指示器
    widget.addEventListener('focus', () => {
      widget.setAttribute('aria-expanded', 'true');
    });

    widget.addEventListener('blur', () => {
      widget.setAttribute('aria-expanded', 'false');
    });
  }

  activateVerification() {
    // 触发验证
    const event = new MouseEvent('click', {
      bubbles: true,
      cancelable: true
    });
    this.container.dispatchEvent(event);
  }

  cancelVerification() {
    // 取消验证
    if (window.turnstile) {
      const widgets = window.turnstile.getAll();
      widgets.forEach(widget => {
        window.turnstile.reset(widget);
      });
    }
  }
}
```

## 最佳实践

1. **保持一致性**：与网站整体设计风格保持一致
2. **响应式设计**：确保在所有设备上都有良好表现
3. **高对比度**：保证足够的对比度以提升可读性
4. **动画适度**：使用流畅但不干扰的动画效果
5. **可访问性**：支持键盘导航和屏幕阅读器
6. **主题切换**：提供明暗主题切换选项
7. **错误反馈**：清晰的错误状态指示
8. **性能优化**：避免过度使用复杂样式
