# Cloudflare Turnstile 免费额度说明

## 免费套餐概览

Cloudflare Turnstile 提供了极为慷慨的免费额度，适合个人项目、小型网站乃至中大型企业使用。

### 免费额度详情

#### 验证次数
- **额度**：每天 1,000,000 次验证
- **重置时间**：UTC 00:00 自动重置
- **包含内容**：所有验证模式的验证
- **超出处理**：超出后验证会失败，返回 429 错误

#### 其他免费资源
- **站点数量**：无限个站点/域名
- **Widget 加载**：无限次加载
- **API 调用**：包含在验证次数内
- **数据保留**：30 天的验证数据
- **技术支持**：社区支持
- **更新频率**：定期功能更新

## 消耗计算规则

### 什么消耗额度
1. **成功的验证**：生成有效 token
2. **失败的验证**：验证失败也计入
3. **超时的验证**：用户超时未完成
4. **无效的请求**：格式错误的请求

### 什么不消耗额度
1. **Widget 加载**：加载脚本不消耗
2. **页面浏览**：仅浏览页面不消耗
3. **服务端验证**：验证 token 不消耗
4. **API 查询**：查询站点信息不消耗

### 2. 缓存验证结果
```javascript
// 客户端缓存
class VerificationCache {
  constructor() {
    this.cache = new Map();
    this.ttl = 300000; // 5分钟缓存
  }

  set(key, value) {
    this.cache.set(key, {
      value,
      timestamp: Date.now()
    });
  }

  get(key) {
    const item = this.cache.get(key);
    if (!item) return null;

    if (Date.now() - item.timestamp > this.ttl) {
      this.cache.delete(key);
      return null;
    }

    return item.value;
  }

  has(key) {
    return this.get(key) !== null;
  }
}

// 使用缓存
const cache = new VerificationCache();

async function verifyWithCache(token) {
  // 检查缓存
  const cached = cache.get(token);
  if (cached) {
    return cached;
  }

  // 执行验证
  const result = await verifyTurnstileToken(token);

  // 缓存结果
  cache.set(token, result);

  return result;
}
```

### 3. 批量验证
```javascript
// 批量处理验证请求
class BatchVerifier {
  constructor() {
    this.queue = [];
    this.batchSize = 10;
    this.batchTimeout = 1000;
    this.timer = null;
  }

  async verify(token) {
    return new Promise((resolve, reject) => {
      this.queue.push({ token, resolve, reject });

      if (this.queue.length >= this.batchSize) {
        this.processBatch();
      } else if (!this.timer) {
        this.timer = setTimeout(() => this.processBatch(), this.batchTimeout);
      }
    });
  }

  async processBatch() {
    if (this.timer) {
      clearTimeout(this.timer);
      this.timer = null;
    }

    const batch = this.queue.splice(0, this.batchSize);

    // 并发处理
    const promises = batch.map(async (item) => {
      try {
        const result = await verifyTurnstileToken(item.token);
        item.resolve(result);
      } catch (error) {
        item.reject(error);
      }
    });

    await Promise.all(promises);
  }
}
```
