## 服务概述

Cloudflare Turnstile 是隐私友好的智能验证系统，无需用户解决的验证码，保护网站免受机器人和滥用。

### 免费额度
- 验证次数：每天 1,000,000 次
- 站点数量：无限个
- Widget加载：无限次
- API调用：包含在验证次数内
- 数据保留：30天
- 支持的域名：无限个

### 核心特性
- **无用户交互** - 大多数情况下无感知验证
- **隐私保护** - 不追踪用户、不使用Cookie
- **快速加载** - 毫秒级响应时间
- **自适应AI** - 智能识别人类和机器人
- **多语言支持** - 支持20+种语言
- **无障碍友好** - 符合WCAG标准

### 验证方式
- **托管模式** - Cloudflare托管Widget
- **非托管模式** - 自行托管验证
- **不可见模式** - 完全透明的验证
- **管理验证** - 强制交互验证

### 适用场景
- **网站登录** - 防止暴力破解
- **注册表单** - 防止垃圾注册
- **评论系统** - 防止垃圾评论
- **API接口** - 防止滥用和爬虫
- **投票系统** - 防止刷票
- **优惠券** - 防止批量领取
- **表单提交** - 防止垃圾数据
