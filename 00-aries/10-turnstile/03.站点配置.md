# Cloudflare Turnstile 站点配置

## 创建 Turnstile 站点

### 1. 登录 Cloudflare Dashboard

访问 [https://dash.cloudflare.com](https://dash.cloudflare.com) 并登录你的 Cloudflare 账户。

### 2. 导航到 Turnstile

1. 在左侧导航栏选择 **Turnstile**
2. 或直接访问：[https://dash.cloudflare.com/?to=/:account/turnstile](https://dash.cloudflare.com/?to=/:account/turnstile)

### 3. 添加站点

点击 **"Add site"** 按钮开始配置新站点。

### 4. 站点配置选项

#### 基本信息
```
站点名称 (Site name)
- 描述性名称，便于管理
- 示例："我的博客登录保护"

域名 (Domains)
- 添加要保护的主域名
- 支持通配符 *.example.com
- 可添加多个域名

示例：
- example.com
- www.example.com
- *.example.com
- api.example.com
```

#### Widget 类型选择
```
托管 (Managed)
- Cloudflare 托管所有资源
- 最简单，推荐使用

非托管 (Non-interactive)
- 自托管验证资源
- 需要额外的服务器配置

不可见 (Invisible)
- 完全透明的验证
- 用户无感知
```

#### 验证模式
```
1. 托管 Widget (Managed Widget)
   - 默认推荐模式
   - 自动显示验证界面
   - 适合大多数场景

2. 不可见验证 (Invisible)
   - 完全无感知
   - 需要额外的客户端集成
   - 适合高度敏感的场景

3. 管理模式 (Managed)
   - 强制显示验证
   - 最高的安全性
   - 适合高风险操作
```

### 5. 高级配置选项

#### 安全级别
```
关 (Off)
- 不进行验证
- 仅用于测试

平衡 (Balanced) - 推荐
- 适中的安全性
- 良好的用户体验

严格 (Strict)
- 最高的安全性
- 可能增加验证次数

最严格 (Strictest)
- 最大程度的安全保障
- 最多的人工验证
```

#### Widget 选项
```
- 自动重新渲染 (Auto-reload)
  失败后自动尝试新的验证

- 超时时间 (Timeout)
  默认 300 秒

- 语言 (Language)
  自动检测或指定特定语言

- 主题 (Theme)
  Light（浅色）/ Dark（深色）/ Auto（自动）
```

## 获取密钥

创建站点后，你会得到两个重要的密钥：

### 站点密钥 (Site Key)
```
用途：
- 前端使用
- 公开显示
- 用于渲染 Widget

示例：
0x4AAAAAAABkMYinukE_dZwr
```

### 密钥 (Secret Key)
```
用途：
- 服务端验证
- 必须保密
- 不能暴露在前端

示例：
0x4AAAAAAABkMYinuG98grX43-Yx7qNAVRqk
```

## 环境配置

### 开发环境
```javascript
// .env 文件
```


## 配置示例代码

### 1. 基本配置
```html
<!DOCTYPE html>
<html>
<head>
  <title>Turnstile 示例</title>
  <script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer></script>
</head>
<body>
  <form action="/verify" method="POST">
    <input type="text" name="username" placeholder="用户名">
    <input type="password" name="password" placeholder="密码">

    <!-- Turnstile Widget -->
    <div class="cf-turnstile"
         data-sitekey="YOUR_SITE_KEY">
    </div>

    <button type="submit">登录</button>
  </form>
</body>
</html>
```

### 2. 高级配置
```html
<!-- 带自定义配置的 Widget -->
<div class="cf-turnstile"
     data-sitekey="YOUR_SITE_KEY"
     data-theme="dark"
     data-language="zh-CN"
     data-tabindex="0"
     data-action="login"
     data-callback="onSuccess"
     data-error-callback="onError"
     data-expired-callback="onExpired"
     data-retry="auto"
     data-retry-interval="1000">
</div>

<script>
function onSuccess(token) {
  console.log('验证成功:', token);
  // 可以自动提交表单
  document.getElementById('loginForm').submit();
}

function onError(error) {
  console.error('验证失败:', error);
  alert('验证失败，请重试');
}

function onExpired() {
  console.log('验证已过期');
  alert('验证已过期，请重新验证');
}
</script>
```

### 3. 动态配置
```javascript
// 根据环境动态配置
const config = {
  development: {
    siteKey: '0x4AAAAAAABkMYinukE_dZwr_dev',
    theme: 'light',
    action: 'dev_login'
  },
  production: {
    siteKey: '0x4AAAAAAABkMYinukE_dZwr',
    theme: 'auto',
    action: 'login'
  }
};

const currentConfig = config[process.env.NODE_ENV] || config.development;

// 动态渲染 Widget
function renderTurnstile() {
  const container = document.getElementById('turnstile-container');
  container.innerHTML = `
    <div class="cf-turnstile"
         data-sitekey="${currentConfig.siteKey}"
         data-theme="${currentConfig.theme}"
         data-action="${currentConfig.action}">
    </div>
  `;

  // 重新加载 Turnstile
  turnstile.render();
}
```

## 安全配置建议

### 1. 密钥管理
```javascript
// 使用环境变量存储密钥
// .env.production
TURNSTILE_SECRET_KEY=your_secret_key_here

// .env.development
TURNSTILE_SECRET_KEY=your_dev_secret_key_here

// Node.js 中使用
const secretKey = process.env.TURNSTILE_SECRET_KEY;

// 永远不要在前端代码中暴露密钥
// ❌ 错误做法
const secretKey = "0x4AAAAAAABkMYinuG98grX43-Yx7qNAVRqk"; // 暴露在前端
```

### 2. 域名限制
```
配置说明：
- 只添加需要的域名
- 使用具体的域名而非通配符
- 定期审查和更新域名列表

示例：
✅ 好的做法
- login.example.com
- register.example.com

❌ 不推荐的做法
- *.com
- *
```

### 3. 环境隔离
```javascript
// 为不同环境创建独立的站点
const environments = {
  development: {
    siteKey: '0x4AAAAAAABkMYinukE_dev',
    domains: ['localhost', '127.0.0.1', '*.dev.example.com']
  },
  staging: {
    siteKey: '0x4AAAAAAABkMYinukE_staging',
    domains: ['staging.example.com', '*.staging.example.com']
  },
  production: {
    siteKey: '0x4AAAAAAABkMYinukE_prod',
    domains: ['example.com', '*.example.com']
  }
};
```

## 故障排除

### 常见问题
1. **"Invalid sitekey"**
   - 检查站点密钥是否正确
   - 确认域名是否在允许列表中

2. **"Invalid secret"**
   - 检查密钥是否正确
   - 确认没有在客户端暴露密钥

3. **"Timeout or duplicate"**
   - 检查网络连接
   - 确认 Token 是否已被使用

4. **Widget 不显示**
   - 检查脚本是否正确加载
   - 确认容器元素是否存在

### 调试技巧

```javascript
window.turnstileDebug = true;

});
```
