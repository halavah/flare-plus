# Cloudflare Queue 免费额度详解

## 免费套餐概述

Cloudflare Queue 提供了慷慨的免费额度，适合小型项目、原型开发和中等规模的应用。

## 免费额度详情

### 1. 操作次数
- **额度**：每天 1,000,000 次操作
- **包含**：发送、接收、删除、确认等所有操作
- **重置**：每天 UTC 00:00 重置
- **超出限制**：操作将被拒绝，返回 429 状态码

### 2. 存储空间
- **额度**：500MB 永久免费
- **包含**：所有队列的消息数据总和
- **监控**：可在 Dashboard 实时查看使用量
- **超出限制**：无法再接受新消息

### 3. 消息大小
- **最大**：128KB 每条消息
- **建议**：保持消息精简，仅包含必要数据
- **优化**：使用引用代替完整对象

### 4. 消息保留
- **默认**：4 天自动删除
- **最长**：可配置 7 天
- **自定义**：支持设置 TTL（Time To Live）

### 5. 队列数量
- **限制**：无限个队列
- **建议**：按功能或服务分离队列
- **命名**：使用有意义的队列名称

### 6. 消费者数量
- **限制**：每个队列无限个消费者
- **并发**：支持高并发消费
- **扩展**：可根据负载自动扩展

## 计费规则（超出免费额度后）

### 1. 操作费用
- 价格：$0.40 每百万次操作
- 计量：按实际操作次数
- 粒度：按 1 万次操作递增

### 2. 存储费用
- 价格：$0.25 每GB每月
- 计量：按小时平均使用量
- 粒度：按 MB 计算

## 成本优化策略

### 1. 批处理
```javascript
// 使用批量操作减少 API 调用
const messages = [
  { body: "message1" },
  { body: "message2" },
  { body: "message3" }
];
await queue.sendBatch(messages);
```

### 2. 消息压缩
```javascript
// 压缩大消息
import { gzip, gunzip } from 'zlib';

const compressed = await gzip(JSON.stringify(largeData));
await queue.send({ body: compressed.toString('base64') });
```

### 3. 及时清理
- 设置合适的 TTL
- 处理完成后立即删除
- 定期清理死信队列

### 4. 监控使用量
```javascript
// 实现使用量监控
async function checkUsage() {
  const analytics = await queue.getAnalytics();
  console.log(`Operations: ${analytics.operations.count}`);
  console.log(`Storage: ${analytics.storage.bytes} bytes`);
}
```

## 最佳实践

### 1. 设计考虑
- 保持消息小巧（< 32KB 推荐）
- 使用引用代替完整数据
- 合理设置消息 TTL

### 2. 架构设计
- 按功能分离队列
- 使用死信队列处理失败消息
- 实现幂等性处理

### 3. 性能优化
- 使用批量操作
- 并行处理消息
- 优化消费者数量

### 4. 错误处理
- 实现重试机制
- 监控错误率
- 设置告警阈值

## 示例：成本估算

假设一个中等规模应用：
- 每小时 10,000 条消息
- 每条消息 10KB
- 消息平均保留 1 天

计算：
- 日操作数：10,000 × 24 × 2（发送+确认）= 480,000 次
- 日存储量：10,000 × 10KB × 24 = 2.4GB（实际由于滚动存储约 240MB）

结果：完全在免费额度内！
