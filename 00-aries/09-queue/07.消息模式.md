# Cloudflare Queue 消息模式

## 消息模式概述

消息模式定义了生产者和消费者之间的消息传递方式。选择合适的消息模式对于构建高效、可扩展的分布式系统至关重要。

## 1. 点对点模式（Point-to-Point）

### 特点
- 一条消息只能被一个消费者接收
- 多个消费者竞争消费同一个队列
- 实现负载均衡和工作分发

### 实现示例
```javascript
// 生产者 - 发送任务到工作队列
export default {
  async fetch(request, env) {
    const task = {
      id: generateTaskId(),
      type: 'image_processing',
      payload: await request.json(),
      createdAt: new Date().toISOString()
    };

    await env.WORK_QUEUE.send({
      body: JSON.stringify(task)
    });

    return new Response(JSON.stringify({ taskId: task.id }));
  }
};

// 消费者 - 工作节点
export default {
  async queue(batch, env) {
    for (const message of batch.messages) {
      const task = JSON.parse(message.body);

      try {
        // 处理任务
        await processTask(task);

        // 确认完成
        message.ack();
      } catch (error) {
        // 处理失败，重新排队
        message.retry();
      }
    }
  }
};
```

### 适用场景
- 任务分发
- 负载均衡
- 工作队列
- 异步任务处理

## 2. 发布订阅模式（Publish-Subscribe）

### 特点
- 一条消息可以被多个消费者接收
- 每个订阅者都会收到消息的副本
- 实现一对多的消息广播

### 实现示例
```javascript
// 发布者 - 发送事件
export default {
  async fetch(request, env) {
    const event = {
      type: 'user_registered',
      userId: 'user-123',
      timestamp: new Date().toISOString(),
      data: await request.json()
    };

    // 发送到主题
    await env.EVENT_TOPIC.send({
      body: JSON.stringify(event)
    });

    return new Response('Event published');
  }
};

// 订阅者1 - 发送欢迎邮件
export default {
  async queue(batch, env) {
    for (const message of batch.messages) {
      const event = JSON.parse(message.body);

      if (event.type === 'user_registered') {
        await sendWelcomeEmail(event.data.email);
        message.ack();
      }
    }
  }
};

// 订阅者2 - 创建用户档案
export default {
  async queue(batch, env) {
    for (const message of batch.messages) {
      const event = JSON.parse(message.body);

      if (event.type === 'user_registered') {
        await createUserProfile(event);
        message.ack();
      }
    }
  }
};
```

### 使用队列模拟发布订阅
```javascript
// 使用多个队列实现发布订阅
const SUBSCRIBERS = {
  'user_registered': [
    'email_notification_queue',
    'profile_creation_queue',
    'analytics_queue'
  ]
};

async function publishEvent(env, event) {
  const subscribers = SUBSCRIBERS[event.type] || [];

  // 发送到所有订阅者队列
  await Promise.all(
    subscribers.map(queueName =>
      env[queueName].send({
        body: JSON.stringify(event)
      })
    )
  );
}
```

### 适用场景
- 事件通知
- 系统解耦
- 数据同步
- 广播消息

## 3. 请求响应模式（Request-Reply）

### 特点
- 同步风格的异步通信
- 使用两个队列实现请求和响应
- 支持超时和关联请求响应

### 实现示例
```javascript
// 请求端
class RPCClient {
  constructor(requestQueue, responseQueue) {
    this.requestQueue = requestQueue;
    this.responseQueue = responseQueue;
    this.pendingRequests = new Map();
  }

  async request(method, params, timeout = 30000) {
    const requestId = this.generateRequestId();
    const request = {
      id: requestId,
      method,
      params,
      timestamp: Date.now()
    };

    // 创建 Promise 等待响应
    const promise = new Promise((resolve, reject) => {
      this.pendingRequests.set(requestId, { resolve, reject });

      // 设置超时
      setTimeout(() => {
        if (this.pendingRequests.has(requestId)) {
          this.pendingRequests.delete(requestId);
          reject(new Error('Request timeout'));
        }
      }, timeout);
    });

    // 发送请求
    await this.requestQueue.send({
      body: JSON.stringify(request),
      metadata: { replyTo: this.responseQueue.name }
    });

    return promise;
  }

  handleResponse(response) {
    const { id, result, error } = JSON.parse(response.body);
    const pending = this.pendingRequests.get(id);

    if (pending) {
      this.pendingRequests.delete(id);
      if (error) {
        pending.reject(new Error(error));
      } else {
        pending.resolve(result);
      }
    }
  }
}

// 响应端（服务端）
export default {
  async queue(batch, env) {
    for (const message of batch.messages) {
      const request = JSON.parse(message.body);

      try {
        // 处理请求
        const result = await handleRequest(request.method, request.params);

        // 发送响应
        const replyTo = message.metadata?.replyTo;
        if (replyTo) {
          await env[replyTo].send({
            body: JSON.stringify({
              id: request.id,
              result,
              timestamp: Date.now()
            })
          });
        }

        message.ack();
      } catch (error) {
        // 发送错误响应
        const replyTo = message.metadata?.replyTo;
        if (replyTo) {
          await env[replyTo].send({
            body: JSON.stringify({
              id: request.id,
              error: error.message,
              timestamp: Date.now()
            })
          });
        }

        message.ack();
      }
    }
  }
};
```

### 适用场景
- 远程过程调用（RPC）
- 同步查询
- 服务间通信
- API 网关

## 4. 工作队列模式（Work Queue）

### 特点
- 多个消费者并行处理任务
- 任务自动分配给可用消费者
- 支持动态扩展和缩减

### 实现示例
```javascript
// 任务分发器
class TaskDistributor {
  constructor(queue) {
    this.queue = queue;
    this.workers = [];
  }

  async submitTask(task, priority = 0) {
    const taskMessage = {
      id: this.generateTaskId(),
      type: task.type,
      payload: task.payload,
      priority,
      createdAt: Date.now()
    };

    await this.queue.send({
      body: JSON.stringify(taskMessage)
    });

    return taskMessage.id;
  }

  async submitBatch(tasks) {
    const messages = tasks.map(task => ({
      body: JSON.stringify({
        id: this.generateTaskId(),
        type: task.type,
        payload: task.payload,
        priority: task.priority || 0,
        createdAt: Date.now()
      })
    }));

    await this.queue.sendBatch(messages);
  }
}

// 工作节点
class Worker {
  constructor(id, queue, handler) {
    this.id = id;
    this.queue = queue;
    this.handler = handler;
    this.processing = false;
  }

  async process() {
    this.processing = true;

    try {
      const batch = await this.queue.receive({
        batchSize: 5,
        waitTimeMs: 5000
      });

      if (batch.messages.length > 0) {
        console.log(`Worker ${this.id} processing ${batch.messages.length} tasks`);

        // 并行处理任务
        await Promise.all(
          batch.messages.map(message => this.handleTask(message))
        );
      }
    } catch (error) {
      console.error(`Worker ${this.id} error:`, error);
    } finally {
      this.processing = false;
    }
  }

  async handleTask(message) {
    try {
      const task = JSON.parse(message.body);
      console.log(`Worker ${this.id} handling task ${task.id}`);

      await this.handler(task);
      message.ack();
    } catch (error) {
      console.error(`Task ${message.id} failed:`, error);
      message.retry();
    }
  }
}

// 使用示例
const distributor = new TaskDistributor(env.TASK_QUEUE);

// 创建多个工作节点
const workers = [];
for (let i = 0; i < 5; i++) {
  workers.push(new Worker(i, env.TASK_QUEUE, async (task) => {
    // 处理任务逻辑
    await doWork(task);
  }));
}

// 启动所有工作节点
workers.forEach(worker => {
  setInterval(() => worker.process(), 1000);
});
```

### 适用场景
- 并行任务处理
- 批处理作业
- 图片/视频处理
- 数据分析

## 5. 路由模式（Routing）

### 特点
- 根据消息内容路由到不同队列
- 支持复杂的路由规则
- 实现智能消息分发

### 实现示例
```javascript
class MessageRouter {
  constructor(rules) {
    this.rules = rules;
  }

  async route(message, env) {
    const data = JSON.parse(message.body);
    let matched = false;

    for (const rule of this.rules) {
      if (this.matchRule(data, rule.condition)) {
        await env[rule.queue].send({
          body: message.body,
          metadata: {
            ...message.metadata,
            routedBy: rule.name
          }
        });
        matched = true;

        // 如果不是多路由，则停止
        if (!rule.multiple) break;
      }
    }

    if (!matched) {
      // 发送到默认队列
      await env.DEFAULT_QUEUE.send(message);
    }
  }

  matchRule(data, condition) {
    if (typeof condition === 'function') {
      return condition(data);
    }

    if (typeof condition === 'object') {
      return Object.entries(condition).every(
        ([key, value]) => data[key] === value
      );
    }

    return false;
  }
}

// 路由规则配置
const routingRules = [
  {
    name: 'high_priority',
    condition: { priority: 'high' },
    queue: 'HIGH_PRIORITY_QUEUE'
  },
  {
    name: 'image_processing',
    condition: (data) => data.type === 'image',
    queue: 'IMAGE_PROCESSING_QUEUE'
  },
  {
    name: 'notification',
    condition: { category: 'notification' },
    queue: 'NOTIFICATION_QUEUE'
  },
  {
    name: 'analytics',
    condition: { category: 'analytics' },
    queue: 'ANALYTICS_QUEUE',
    multiple: true // 可以同时路由到其他队列
  }
];

// 使用路由器
const router = new MessageRouter(routingRules);

export default {
  async fetch(request, env) {
    const message = {
      body: await request.text()
    };

    await router.route(message, env);
    return new Response('Message routed');
  }
};
```

### 适用场景
- 内容分发
- 条件路由
- 智能调度
- 消息分类

## 6. 消息聚合模式（Message Aggregation）

### 特点
- 收集多个相关消息
- 聚合后批量处理
- 减少处理开销

### 实现示例
```javascript
class MessageAggregator {
  constructor(outputQueue, options = {}) {
    this.outputQueue = outputQueue;
    this.batchSize = options.batchSize || 10;
    this.timeout = options.timeout || 5000;
    this.buffer = [];
    this.timer = null;
  }

  async add(message) {
    this.buffer.push({
      ...message,
      aggregatedAt: Date.now()
    });

    if (this.buffer.length >= this.batchSize) {
      await this.flush();
    } else {
      this.scheduleFlush();
    }
  }

  scheduleFlush() {
    if (this.timer) {
      clearTimeout(this.timer);
    }

    this.timer = setTimeout(() => {
      if (this.buffer.length > 0) {
        this.flush();
      }
    }, this.timeout);
  }

  async flush() {
    if (this.buffer.length === 0) return;

    const batch = [...this.buffer];
    this.buffer = [];
    this.timer = null;

    // 创建聚合消息
    const aggregated = {
      type: 'aggregated_batch',
      count: batch.length,
      messages: batch.map(msg => ({
        id: msg.id,
        body: msg.body,
        timestamp: msg.timestamp
      })),
      aggregatedAt: Date.now()
    };

    await this.outputQueue.send({
      body: JSON.stringify(aggregated)
    });

    // 确认所有原始消息
    for (const message of batch) {
      message.ack();
    }
  }
}

// 消费者处理聚合消息
export default {
  async queue(batch, env) {
    for (const message of batch.messages) {
      const data = JSON.parse(message.body);

      if (data.type === 'aggregated_batch') {
        // 批量处理聚合的消息
        await processAggregatedBatch(data);
        message.ack();
      }
    }
  }
};
```

### 适用场景
- 批量处理
- 减少数据库写入
- 降低网络开销
- 提高吞吐量

## 7. 模式选择指南

### 选择标准

| 场景 | 推荐模式 | 特点 |
|------|----------|------|
| 任务分发 | 工作队列 | 负载均衡，并行处理 |
| 事件通知 | 发布订阅 | 一对多广播 |
| 同步查询 | 请求响应 | 同步风格，超时处理 |
| 消息分类 | 路由模式 | 智能分发，条件匹配 |
| 批量操作 | 消息聚合 | 减少开销，提高效率 |
| 简单队列 | 点对点 | 一对一，简单可靠 |

### 组合使用
```javascript
// 组合使用多种模式
class HybridMessagingSystem {
  constructor(env) {
    this.env = env;
    this.router = new MessageRouter(routingRules);
    this.aggregator = new MessageAggregator(env.AGGREGATED_QUEUE);
  }

  async process(message) {
    // 1. 路由消息
    await this.router.route(message, this.env);

    // 2. 某些类型的消息需要聚合
    const data = JSON.parse(message.body);
    if (data.requiresAggregation) {
      await this.aggregator.add(message);
    }
  }
}
```
