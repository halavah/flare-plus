# Cloudflare Queue 监控调试

## 监控概述

有效的监控和调试是确保队列系统稳定运行的关键。Cloudflare Queue 提供了多种监控工具和调试方法，帮助开发者了解队列状态、识别问题并优化性能。

## 1. 内置监控指标

### 核心指标
- **消息数量**：队列中当前消息数
- **消息年龄**：最老消息的存留时间
- **操作次数**：发送、接收、删除等操作计数
- **错误率**：失败操作的百分比
- **延迟**：消息从发送到接收的时间

### 消费者健康检查
```javascript
class ConsumerHealthChecker {
  constructor(queue, consumerName) {
    this.queue = queue;
    this.consumerName = consumerName;
    this.lastActivity = Date.now();
    this.processedMessages = 0;
    this.errorCount = 0;
  }

  recordActivity(success = true) {
    this.lastActivity = Date.now();
    if (success) {
      this.processedMessages++;
    } else {
      this.errorCount++;
    }
  }

  getHealth() {
    const timeSinceLastActivity = Date.now() - this.lastActivity;
    const errorRate = this.errorCount / (this.processedMessages + this.errorCount);

    return {
      consumerName: this.consumerName,
      isHealthy: timeSinceLastActivity < 300000 && errorRate < 0.1, // 5分钟，错误率<10%
      timeSinceLastActivity,
      processedMessages: this.processedMessages,
      errorCount: this.errorCount,
      errorRate: (errorRate * 100).toFixed(2) + '%'
    };
  }
}
```

```javascript
class QueueDashboard {
  constructor(queues) {
    this.queues = queues;
    this.metrics = new Map();
    this.startTime = Date.now();
  }

  async collectMetrics() {
    const timestamp = Date.now();

    for (const [name, queue] of this.queues) {
      const stats = await queue.getStats();
      const consumerStats = await this.getConsumerStats(queue);

      this.metrics.set(name, {
        timestamp,
        queueStats: stats,
        consumerStats,
        trends: this.calculateTrends(name)
      });
    }

    return this.getDashboardData();
  }

  calculateTrends(queueName) {
    const history = this.getMetricHistory(queueName);
    if (history.length < 2) return null;

    const latest = history[history.length - 1];
    const previous = history[history.length - 2];

    return {
      messageCountTrend: latest.queueStats.messageCount - previous.queueStats.messageCount,
      avgProcessingTime: this.calculateAvgProcessingTime(history),
      throughput: this.calculateThroughput(history)
    };
  }

  getDashboardData() {
    const dashboard = {
      timestamp: new Date().toISOString(),
      uptime: Date.now() - this.startTime,
      queues: {}
    };

    for (const [name, data] of this.metrics) {
      dashboard.queues[name] = {
        messageCount: data.queueStats.approximateMessageCount,
        oldestMessage: this.formatDuration(data.queueStats.approximateAgeOfOldestMessage),
        consumerHealth: data.consumerStats.isHealthy ? 'Healthy' : 'Unhealthy',
        throughput: data.trends?.throughput || 0,
        alerts: this.checkAlerts(data)
      };
    }

    return dashboard;
  }

  checkAlerts(data) {
    const alerts = [];

    // 消息积压告警
    if (data.queueStats.approximateMessageCount > 10000) {
      alerts.push({
        type: 'HIGH_BACKLOG',
        severity: 'WARNING',
        message: `High message backlog: ${data.queueStats.approximateMessageCount}`
      });
    }

    // 老消息告警
    if (data.queueStats.approximateAgeOfOldestMessage > 3600000) { // 1小时
      alerts.push({
        type: 'OLD_MESSAGES',
        severity: 'ERROR',
        message: `Old messages detected: ${this.formatDuration(data.queueStats.approximateAgeOfOldestMessage)}`
      });
    }

    // 消费者不健康告警
    if (!data.consumerStats.isHealthy) {
      alerts.push({
        type: 'CONSUMER_UNHEALTHY',
        severity: 'CRITICAL',
        message: `Consumer is unhealthy: ${data.consumerStats.timeSinceLastActivity}ms since last activity`
      });
    }

    return alerts;
  }
}
```

### 性能指标收集器
```javascript
class QueueMetricsCollector {
  constructor() {
    this.metrics = {
      operations: {
        send: { count: 0, totalLatency: 0, errors: 0 },
        receive: { count: 0, totalLatency: 0, errors: 0 },
        delete: { count: 0, totalLatency: 0, errors: 0 }
      },
      messages: {
        sent: 0,
        received: 0,
        processed: 0,
        failed: 0
      },
      timing: {
        avgProcessingTime: 0,
        p95ProcessingTime: 0,
        p99ProcessingTime: 0
      }
    };
    this.processingTimes = [];
  }

  recordOperation(operation, latency, success = true) {
    const op = this.metrics.operations[operation];
    if (op) {
      op.count++;
      op.totalLatency += latency;
      if (!success) op.errors++;
    }
  }

  recordMessage(event, processingTime = null) {
    switch (event) {
      case 'sent':
        this.metrics.messages.sent++;
        break;
      case 'received':
        this.metrics.messages.received++;
        break;
      case 'processed':
        this.metrics.messages.processed++;
        if (processingTime) {
          this.processingTimes.push(processingTime);
          this.updateTimingMetrics();
        }
        break;
      case 'failed':
        this.metrics.messages.failed++;
        break;
    }
  }

  updateTimingMetrics() {
    if (this.processingTimes.length === 0) return;

    // 保留最近1000个样本
    if (this.processingTimes.length > 1000) {
      this.processingTimes = this.processingTimes.slice(-1000);
    }

    const sorted = [...this.processingTimes].sort((a, b) => a - b);
    const sum = this.processingTimes.reduce((a, b) => a + b, 0);

    this.metrics.timing.avgProcessingTime = sum / this.processingTimes.length;
    this.metrics.timing.p95ProcessingTime = sorted[Math.floor(sorted.length * 0.95)];
    this.metrics.timing.p99ProcessingTime = sorted[Math.floor(sorted.length * 0.99)];
  }

  getMetrics() {
    return {
      ...this.metrics,
      timestamp: new Date().toISOString()
    };
  }
}
```

### 结构化日志
```javascript
class QueueLogger {
  constructor(queueName) {
    this.queueName = queueName;
  }

  log(level, message, context = {}) {
    const logEntry = {
      timestamp: new Date().toISOString(),
      level,
      queue: this.queueName,
      message,
      context,
      traceId: this.generateTraceId()
    };

    console.log(JSON.stringify(logEntry));
  }

  logSend(messageId, size, latency) {
    this.log('INFO', 'Message sent', {
      operation: 'send',
      messageId,
      size,
      latency
    });
  }

  logReceive(batchSize, messageId) {
    this.log('INFO', 'Messages received', {
      operation: 'receive',
      batchSize,
      messageId
    });
  }

  logProcessing(messageId, processingTime, success, error = null) {
    this.log(success ? 'INFO' : 'ERROR', 'Message processed', {
      operation: 'process',
      messageId,
      processingTime,
      success,
      error: error?.message
    });
  }

  logError(operation, error, context = {}) {
    this.log('ERROR', `${operation} failed`, {
      operation,
      error: error.message,
      stack: error.stack,
      ...context
    });
  }

  generateTraceId() {
    return Math.random().toString(36).substring(2, 15);
  }
}

// 使用示例
const logger = new QueueLogger('my-queue');

export default {
  async queue(batch, env) {
    const startTime = Date.now();

    try {
      for (const message of batch.messages) {
        const processStart = Date.now();

        try {
          await processMessage(message);
          const processingTime = Date.now() - processStart;
          logger.logProcessing(message.id, processingTime, true);
          message.ack();
        } catch (error) {
          const processingTime = Date.now() - processStart;
          logger.logProcessing(message.id, processingTime, false, error);
          logger.logError('process_message', error, { messageId: message.id });
        }
      }
    } finally {
      const totalTime = Date.now() - startTime;
      logger.log('INFO', 'Batch processed', {
        batchSize: batch.messages.length,
        totalTime
      });
    }
  }
};
```

## 4. 调试工具和技巧

### 消息追踪器
```javascript
class MessageTracker {
  constructor() {
    this.trackedMessages = new Map();
  }

  track(messageId, metadata = {}) {
    this.trackedMessages.set(messageId, {
      id: messageId,
      createdAt: Date.now(),
      status: 'created',
      events: [{ type: 'created', timestamp: Date.now() }],
      ...metadata
    });
  }

  updateStatus(messageId, status, details = {}) {
    const tracking = this.trackedMessages.get(messageId);
    if (tracking) {
      tracking.status = status;
      tracking.events.push({
        type: status,
        timestamp: Date.now(),
        ...details
      });
    }
  }

  getTracking(messageId) {
    return this.trackedMessages.get(messageId);
  }

  getLifetime(messageId) {
    const tracking = this.trackedMessages.get(messageId);
    if (tracking) {
      return Date.now() - tracking.createdAt;
    }
    return null;
  }

  // 清理旧的追踪数据
  cleanup(olderThan = 3600000) { // 1小时
    const cutoff = Date.now() - olderThan;
    for (const [id, tracking] of this.trackedMessages) {
      if (tracking.createdAt < cutoff) {
        this.trackedMessages.delete(id);
      }
    }
  }
}

// 使用示例
const tracker = new MessageTracker();

// 发送消息时追踪
async function sendMessage(queue, message) {
  const messageId = generateMessageId();
  tracker.track(messageId, { queue: queue.name, size: message.length });

  try {
    await queue.send({ ...message, messageId });
    tracker.updateStatus(messageId, 'sent');
  } catch (error) {
    tracker.updateStatus(messageId, 'send_failed', { error: error.message });
  }

  return messageId;
}
```

```javascript
class QueueDebugger {
  constructor(queue) {

      waitTimeMs: 1000

      console.log('===================\n');

      // 不确认消息，保留在队列中
      return batch.messages[0];
    }

    return null;
  }

  async inspectQueue() {
    const stats = await this.queue.getStats();
    console.log('\n=== Queue Inspection ===');
    console.log('Message Count:', stats.approximateMessageCount);
    console.log('Oldest Message Age:', this.formatDuration(stats.approximateAgeOfOldestMessage));
    console.log('Created At:', new Date(stats.createdTimestamp).toISOString());
```

### 错误诊断工具
```javascript
class ErrorDiagnostic {
  constructor() {
    this.errorPatterns = new Map();
    this.setupCommonPatterns();
  }

  setupCommonPatterns() {
    this.errorPatterns.set('timeout', {
      pattern: /timeout/i,
      suggestion: 'Increase timeout or optimize processing',
      severity: 'warning'
    });

    this.errorPatterns.set('memory', {
      pattern: /memory|out of space/i,
      suggestion: 'Check memory usage or reduce batch size',
      severity: 'critical'
    });

    this.errorPatterns.set('network', {
      pattern: /network|connection|econnrefused/i,
      suggestion: 'Check network connectivity',
      severity: 'error'
    });

    this.errorPatterns.set('permission', {
      pattern: /permission|unauthorized|forbidden/i,
      suggestion: 'Check IAM permissions',
      severity: 'critical'
    });
  }

  diagnose(error) {
    const diagnosis = {
      error: error.message,
      type: 'unknown',
      severity: 'error',
      suggestion: 'Unknown error',
      code: error.code
    };

    for (const [type, config] of this.errorPatterns) {
      if (config.pattern.test(error.message)) {
        diagnosis.type = type;
        diagnosis.severity = config.severity;
        diagnosis.suggestion = config.suggestion;
        break;
      }
    }

    return diagnosis;
  }

  async diagnoseAndLog(error, context = {}) {
    const diagnosis = this.diagnose(error);

    console.error('Error Diagnosis:', {
      ...diagnosis,
      context,
      timestamp: new Date().toISOString()
    });

    return diagnosis;
  }
}
```

## 5. 监控告警实现

### 告警系统
```javascript
class AlertManager {
  constructor(webhookUrl) {
    this.webhookUrl = webhookUrl;
    this.alertThresholds = {
      messageCount: 10000,
      oldestMessage: 3600000, // 1小时
      errorRate: 0.1, // 10%
      processingTime: 30000 // 30秒
    };
    this.alertCooldown = new Map();
  }

  async checkAlerts(metrics) {
    const alerts = [];

    // 检查消息积压
    if (metrics.messageCount > this.alertThresholds.messageCount) {
      alerts.push({
        type: 'HIGH_BACKLOG',
        severity: 'warning',
        message: `Message backlog: ${metrics.messageCount}`,
        value: metrics.messageCount
      });
    }

    // 检查老消息
    if (metrics.oldestMessage > this.alertThresholds.oldestMessage) {
      alerts.push({
        type: 'OLD_MESSAGES',
        severity: 'critical',
        message: `Oldest message age: ${this.formatDuration(metrics.oldestMessage)}`,
        value: metrics.oldestMessage
      });
    }

    // 检查错误率
    const errorRate = metrics.errors / (metrics.operations || 1);
    if (errorRate > this.alertThresholds.errorRate) {
      alerts.push({
        type: 'HIGH_ERROR_RATE',
        severity: 'error',
        message: `Error rate: ${(errorRate * 100).toFixed(2)}%`,
        value: errorRate
      });
    }

    // 发送告警
    for (const alert of alerts) {
      await this.sendAlert(alert);
    }
  }

  async sendAlert(alert) {
    // 检查冷却期
    const cooldownKey = `${alert.type}_${alert.severity}`;
    const lastAlert = this.alertCooldown.get(cooldownKey);

    if (lastAlert && Date.now() - lastAlert < 300000) { // 5分钟冷却
      return;
    }

    const payload = {
      text: `🚨 Queue Alert: ${alert.type}`,
      blocks: [
        {
          type: 'section',
          text: {
            type: 'mrkdwn',
            text: `*${alert.severity.toUpperCase()}* - ${alert.message}`
          }
        },
        {
          type: 'section',
          fields: [
            {
              type: 'mrkdwn',
              text: `*Type:* ${alert.type}`
            },
            {
              type: 'mrkdwn',
              text: `*Severity:* ${alert.severity}`
            },
            {
              type: 'mrkdwn',
              text: `*Time:* ${new Date().toISOString()}`
            }
          ]
        }
      ]
    };

    try {
      await fetch(this.webhookUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(payload)
      });

      this.alertCooldown.set(cooldownKey, Date.now());
    } catch (error) {
      console.error('Failed to send alert:', error);
    }
  }

  formatDuration(ms) {
    const seconds = Math.floor(ms / 1000);
    const minutes = Math.floor(seconds / 60);
    const hours = Math.floor(minutes / 60);

    if (hours > 0) return `${hours}h ${minutes % 60}m`;
    if (minutes > 0) return `${minutes}m ${seconds % 60}s`;
    return `${seconds}s`;
  }
}
```

## 6. 性能优化建议

### 监控优化
1. **采样策略**：对高频操作使用采样
2. **批量指标**：聚合指标后批量上报
3. **异步处理**：监控数据异步上报
4. **本地缓存**：缓存频繁查询的指标

### 调试优化
1. **条件调试**：只在特定条件下启用详细日志
2. **内存限制**：限制调试数据存储量
3. **自动清理**：定期清理旧的追踪数据
4. **分级日志**：使用不同的日志级别
