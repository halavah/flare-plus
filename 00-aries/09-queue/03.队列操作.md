# Cloudflare Queue 队列操作

## 基本操作概览

Cloudflare Queue 提供了完整的队列管理 API，支持创建、发送、接收、删除等核心操作。

## 1. 创建队列

### 使用 wrangler CLI
```bash
# 创建新队列
wrangler queues create my-queue

# 创建带配置的队列
wrangler queues create my-queue \
  --message-retention-period 7d \
  --dead-letter-queue my-dlq
```

### 在 wrangler.toml 中定义
```toml
[[queues.producers]]
  binding = "MY_QUEUE"
  queue = "my-queue"

[[queues.consumers]]
  queue = "my-queue"
  dead_letter_queue = "my-dlq"
  max_batch_size = 10
  max_wait_time_ms = 5000
```

## 2. 发送消息

### 单条消息发送
```javascript
// 在 Worker 中发送单条消息
export default {
  async fetch(request, env, ctx) {
    const message = {
      body: JSON.stringify({
        id: "12345",
        type: "user_registration",
        data: { email: "user@example.com" }
      })
    };

    await env.MY_QUEUE.send(message);

    return new Response("Message sent");
  }
};
```

### 批量发送消息
```javascript
// 批量发送提高效率
const messages = [
  {
    body: JSON.stringify({ id: "1", task: "process_image" })
  },
  {
    body: JSON.stringify({ id: "2", task: "send_email" })
  },
  {
    body: JSON.stringify({ id: "3", task: "update_stats" })
  }

await env.MY_QUEUE.sendBatch(messages);
```

### 带延迟发送
```javascript
// 设置消息延迟
const message = {
  body: JSON.stringify({ task: "send_reminder" }),
  delaySeconds: 3600 // 1小时后发送

await env.MY_QUEUE.send(message);
```

## 3. 接收消息

### 配置消费者
```javascript
// 在 wrangler.toml 中配置消费者
[[queues.consumers]]
  queue = "my-queue"
  max_batch_size = 25      // 最大批处理大小
  max_wait_time_ms = 5000  // 最长等待时间
  max_retries = 3          // 最大重试次数
```

### 消费消息
```javascript
export default {
  async queue(batch, env) {
    // batch.messages 包含消息数组
    for (const message of batch.messages) {
      try {
        // 处理消息
        const data = JSON.parse(message.body);
        await processMessage(data);

        // 消息处理成功
        message.ack();
      } catch (error) {
        // 处理失败
        console.error("Processing failed:", error);
        message.retry();
      }
    }
  }
};
```

### 批处理优化
```javascript
// 使用 Promise.all 并行处理
async function processBatch(messages) {
  const results = await Promise.allSettled(
    messages.map(msg => processSingleMessage(msg))
  );

  // 检查结果
  results.forEach((result, index) => {
    if (result.status === 'fulfilled') {
      messages[index].ack();
    } else {
      messages[index].retry();
    }
  });
}
```

## 5. 队列管理

### 获取队列信息
```javascript
// 获取队列统计
const stats = await env.MY_QUEUE.getStats();
console.log({
  approximateMessageCount: stats.approximateMessageCount,
  approximateAgeOfOldestMessage: stats.approximateAgeOfOldestMessage,
  createdTimestamp: stats.createdTimestamp
});
```

### 清空队列
```javascript
// 批量删除所有消息
async function purgeQueue(queue) {
  let hasMore = true;
  while (hasMore) {
    const batch = await queue.receive({
      batchSize: 25,
      waitTimeMs: 1000
    });

    if (batch.messages.length > 0) {
      await queue.deleteBatch(batch.messages.map(m => m.receiptHandle));
    } else {
      hasMore = false;
    }
  }
}
```

### 队列监控
```javascript
// 监控队列健康状态
async function monitorQueue(queue) {
  const stats = await queue.getStats();
  const backlog = stats.approximateMessageCount;
  const oldestAge = stats.approximateAgeOfOldestMessage;

  if (backlog > 10000) {
    console.warn(`High backlog: ${backlog} messages`);
  }

  if (oldestAge > 3600000) { // 1小时
    console.warn(`Old messages detected: ${oldestAge}ms`);
  }
}
```

## 6. 错误处理

### 常见错误码
- `400` - 请求格式错误
- `401` - 认证失败
- `403` - 权限不足
- `404` - 队列不存在
- `413` - 消息过大
- `429` - 超出速率限制
- `500` - 服务器错误

### 错误处理示例
```javascript
async function safeSendMessage(queue, message) {
  try {
    await queue.send(message);
    return { success: true };
  } catch (error) {
    if (error.status === 413) {
      return {
        success: false,
        error: "Message too large",
        suggestion: "Compress or split message"
      };
    } else if (error.status === 429) {
      await delay(1000);
      return safeSendMessage(queue, message); // 重试
    } else {
      throw error;
    }
  }
}
```

## 7. 最佳实践

### 消息设计
- 保持消息小巧（< 32KB）
- 使用 JSON 格式
- 包含必要的元数据
- 实现幂等性

### 批处理
- 尽可能使用批量操作
- 调整批处理大小以平衡延迟和吞吐量
- 设置合理的等待时间

### 性能优化
```javascript
// 使用连接池
const queueConnections = new Map();

function getQueue(name) {
  if (!queueConnections.has(name)) {
    queueConnections.set(name, new Queue(name));
  }
  return queueConnections.get(name);
}

// 使用缓冲区批量发送
const messageBuffer = [];
setInterval(async () => {
  if (messageBuffer.length > 0) {
    await queue.sendBatch([...messageBuffer]);
    messageBuffer.length = 0;
  }
}, 1000);
```
