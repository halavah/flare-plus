## 服务概述

Cloudflare Queue 是完全托管的消息队列服务，支持异步消息处理和解耦应用组件。

### 免费额度
- 操作次数：每天 1,000,000 次
- 存储空间：500MB
- 消息大小：最大 128KB
- 保留时间：默认 4天（可配置7天）
- 队列数量：无限个
- 消费者：每个队列无限个

### 核心特性
- **至少一次** - 消息保证至少投递一次
- **自动扩展** - 无需预配置容量
- **全球分布** - 消息自动路由到最近节点
- **批处理支持** - 提高吞吐量
- **死信队列** - 处理失败消息
- **过滤器** - 支持消息路由和过滤

### 使用场景
- **异步任务处理** - 图片处理、视频转码
- **订单处理** - 电商订单异步处理
- **通知系统** - 邮件、短信、推送通知
- **数据管道** - ETL数据处理
- **微服务通信** - 服务间解耦
- **工作流引擎** - 长时间运行任务
- **事件溯源** - 事件流处理
- **批处理作业** - 定时批处理任务
