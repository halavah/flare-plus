# Cloudflare Queue 批处理

## 批处理概述

批处理是优化队列性能的关键技术，通过批量发送和接收消息可以显著提高吞吐量，减少 API 调用次数，降低成本。

## 1. 批处理的优势

### 性能提升
- **减少网络往返**：一次 API 调用处理多条消息
- **提高吞吐量**：每秒可处理更多消息
- **降低延迟**：减少单条消息的处理开销

### 成本优化
- **减少操作次数**：计入免费额度的操作更少
- **提高效率**：相同的资源处理更多工作
- **降低单位成本**：批量操作的摊薄成本更低

### 资源优化
- **减少 CPU 使用**：减少序列化/反序列化开销
- **降低内存占用**：共享连接和缓冲区
- **减少 I/O 操作**：合并写入操作

### 分批处理大量消息
```javascript
async function sendLargeBatch(queue, messages, batchSize = 10) {
  for (let i = 0; i < messages.length; i += batchSize) {
    const batch = messages.slice(i, i + batchSize);

    try {
      await queue.sendBatch(batch);
      console.log(`Sent batch ${Math.floor(i/batchSize) + 1}`);
    } catch (error) {
      console.error(`Batch ${Math.floor(i/batchSize) + 1} failed:`, error);

      // 可选：重试失败的批次
      await retrySend(queue, batch);
    }
  }
}
```

### 带限流的批量发送
```javascript
class RateLimitedSender {
  constructor(queue, ratePerSecond) {
    this.queue = queue;
    this.minInterval = 1000 / ratePerSecond;
    this.lastSend = 0;
  }

  async sendBatch(messages) {
    // 限制发送速率
    const elapsed = Date.now() - this.lastSend;
    if (elapsed < this.minInterval) {
      await delay(this.minInterval - elapsed);
    }

    this.lastSend = Date.now();
    return await this.queue.sendBatch(messages);
  }
}

// 使用示例
const sender = new RateLimitedSender(env.MY_QUEUE, 10); // 每秒10次
await sender.sendBatch(messages);
```

### 高效批处理实现
```javascript
export default {
  async queue(batch, env) {
    const startTime = Date.now();
    const { messages } = batch;

    // 预处理：解析所有消息
    const parsedMessages = messages.map(msg => ({
      ...msg,
      data: JSON.parse(msg.body)
    }));

    // 分组处理（按类型或优先级）
    const grouped = groupByType(parsedMessages);

    // 并行处理各组
    await Promise.all(
      Object.entries(grouped).map(([type, msgs]) =>
        processMessagesByType(type, msgs)
      )
    );

    // 批量确认
    for (const message of messages) {
      message.ack();
    }

    // 记录指标
    const duration = Date.now() - startTime;
    console.log(`Processed ${messages.length} messages in ${duration}ms`);
  }
};

function groupByType(messages) {
  return messages.reduce((groups, msg) => {
    const type = msg.data.type || 'default';
    if (!groups[type]) groups[type] = [];
    groups[type].push(msg);
    return groups;
  }, {});
}
```

### 动态批处理大小
```javascript
class AdaptiveBatchProcessor {
  constructor() {
    this.avgProcessingTime = 1000; // 初始估计
    this.targetProcessingTime = 5000; // 目标处理时间
  }

  async processBatch(messages) {
    const start = Date.now();

    // 处理消息
    await this.processMessages(messages);

    const actualTime = Date.now() - start;

    // 调整批处理大小
    this.adjustBatchSize(messages.length, actualTime);
  }

  adjustBatchSize(currentSize, actualTime) {
    const ratio = actualTime / this.targetProcessingTime;

    if (ratio > 1.2) {
      // 处理太慢，减小批处理大小
      this.optimalSize = Math.max(1, Math.floor(currentSize * 0.8));
    } else if (ratio < 0.8) {
      // 处理太快，增加批处理大小
      this.optimalSize = Math.min(100, Math.ceil(currentSize * 1.2));
    }
  }
}
```

## 4. 批处理模式

### 1. 固定大小批处理
```javascript
async function processFixedSizeBatch(queue, batchSize = 10) {
  const messages = [];

  // 收集固定数量的消息
  while (messages.length < batchSize) {
    const batch = await queue.receive({
      batchSize: 1,
      waitTimeMs: 1000
    });

    if (batch.messages.length > 0) {
      messages.push(...batch.messages);
    } else {
      break; // 没有更多消息
    }
  }

  if (messages.length > 0) {
    await processBatch(messages);
  }
}
```

### 2. 时间窗口批处理
```javascript
class TimeWindowBatcher {
  constructor(windowMs = 1000) {
    this.windowMs = windowMs;
    this.buffer = [];
    this.timer = null;
  }

  add(message) {
    this.buffer.push(message);

    if (!this.timer) {
      this.timer = setTimeout(() => {
        this.flush();
      }, this.windowMs);
    }
  }

  async flush() {
    if (this.buffer.length === 0) return;

    const batch = [...this.buffer];
    this.buffer = [];
    this.timer = null;

    await processBatch(batch);
  }
}
```

### 3. 智能批处理
```javascript
class SmartBatcher {
  constructor(options = {}) {
    this.maxSize = options.maxSize || 100;
    this.maxWait = options.maxWait || 5000;
    this.minSize = options.minSize || 10;
    this.buffer = [];
    this.lastFlush = Date.now();
  }

  add(message) {
    this.buffer.push(message);

    // 检查是否需要刷新
    if (this.shouldFlush()) {
      this.flush();
    }
  }

  shouldFlush() {
    const sizeExceeded = this.buffer.length >= this.maxSize;
    const waitExceeded = Date.now() - this.lastFlush >= this.maxWait;
    const minReached = this.buffer.length >= this.minSize;

    return sizeExceeded || (waitExceeded && minReached);
  }

  async flush() {
    if (this.buffer.length === 0) return;

    const batch = [...this.buffer];
    this.buffer = [];
    this.lastFlush = Date.now();

    await processBatch(batch);
  }
}
```

### 3. 工作窃取
```javascript
class WorkStealingProcessor {
  constructor(workers) {
    this.workers = workers;
    this.queues = new Map();
  }

  async process() {
    const promises = this.workers.map(worker =>
      this.workerLoop(worker)
    );

    await Promise.all(promises);
  }

  async workerLoop(worker) {
    while (true) {
      // 尝试从自己的队列获取
      let batch = await this.getFromQueue(worker.queueId);

      // 如果自己的队列为空，尝试窃取其他队列的工作
      if (!batch || batch.messages.length === 0) {
        batch = await this.stealWork(worker);
      }

      if (batch && batch.messages.length > 0) {
        await worker.process(batch);
      } else {
        await delay(100); // 避免忙等待
      }
    }
  }
}
```

## 6. 监控和调试

### 批处理指标
```javascript
class BatchMetrics {
  constructor() {
    this.stats = {
      batchesProcessed: 0,
      messagesProcessed: 0,
      avgBatchSize: 0,
      avgProcessingTime: 0,
      errorRate: 0
    };
  }

  record(batch, processingTime, errors = 0) {
    this.stats.batchesProcessed++;
    this.stats.messagesProcessed += batch.length;
    this.stats.avgBatchSize = this.updateAvg(
      this.stats.avgBatchSize,
      batch.length,
      this.stats.batchesProcessed
    );
    this.stats.avgProcessingTime = this.updateAvg(
      this.stats.avgProcessingTime,
      processingTime,
      this.stats.batchesProcessed
    );
    this.stats.errorRate = (errors / batch.length) * 100;
  }

  updateAvg(current, value, count) {
    return (current * (count - 1) + value) / count;
  }
}
```

## 7. 最佳实践总结

1. **选择合适的批处理大小**
   - 开始时使用 10-25 条消息
   - 根据处理时间动态调整
   - 考虑消息大小和复杂度

2. **设置合理的等待时间**
   - 平衡延迟和吞吐量
   - 典型值：1-5 秒
   - 根据业务需求调整

3. **实现错误处理**
   - 记录失败的消息
   - 实现重试机制
   - 使用死信队列

4. **监控性能指标**
   - 批处理大小
   - 处理时间
   - 成功率

5. **优化资源使用**
   - 重用连接
   - 预分配内存
   - 并行处理独立任务
