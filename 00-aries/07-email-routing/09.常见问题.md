# Email Routing 常见问题

## ❓ 基础问题

### Q1: Email Routing 是什么？它是如何工作的？

**A:** Email Routing 是 Cloudflare 提供的邮件路由服务，允许你接收、处理和转发电子邮件。工作原理如下：

1. **接收邮件**：通过 MX 记录将你的域名邮件路由到 Cloudflare
2. **处理邮件**：使用 Workers 对邮件进行自定义处理
3. **路由决策**：根据规则决定邮件的去向
4. **执行动作**：转发、存储、回复或其他自定义动作

```javascript
// 基础邮件处理流程示例
export default {
  async email(message, env, ctx) {
    // 1. 接收邮件
    const from = message.from;
    const to = message.to;

    // 2. 处理邮件
    console.log(`Email from ${from} to ${to}`);

    // 3. 路由决策
    if (shouldForward(to)) {
      // 4. 转发邮件
      await message.forward('user@example.com');
    }

    return new Response('OK');
  }
};
```

### Q2: 如何设置域名以使用 Email Routing？

**A:** 设置步骤：

1. **更新 MX 记录**：
   ```
   Type: MX
   Name: @ (或你的域名)
   Value: mx.your-domain.com.cf-protect.net
   Priority: 10
   ```

2. **添加 SPF 记录**：
   ```
   Type: TXT
   Name: @
   Value: "v=spf1 include:_spf.mx.cloudflare.net ~all"
   ```

3. **配置 DKIM**（可选）：
   - 在 Cloudflare 生成 DKIM 密钥
   - 添加 CNAME 记录

### Q3: Email Routing 的免费限制是什么？

async function archiveEmail(email, env) {

  const archiveKey = `archive/${email.id}.eml`;

  // 从 R2 复制到归档
  const original = await env.EMAIL_BUCKET.get(email.storage_path);

  await env.EMAIL_BUCKET.delete(email.storage_path);

### Q16: 如何实现邮件的实时处理？

**A:** 实时处理方案：

1. **WebSocket 实时推送**
```javascript
export class EmailNotifier {
  constructor(state, env) {
    this.state = state;
    this.env = env;
    this.clients = new Map();
  }

  async fetch(request) {
    if (request.url.endsWith('/ws')) {
      return this.handleWebSocket(request);
    }
  }

  async handleWebSocket(request) {
    const pair = new WebSocketPair();
    const [client, server] = pair;

    await this.state.acceptWebSocket(server);

    // 添加客户端
    const clientId = crypto.randomUUID();
    this.clients.set(clientId, server);

    // 处理消息
    server.addEventListener('message', async (event) => {
      const message = JSON.parse(event.data);

      if (message.type === 'subscribe') {
        // 订阅实时通知
        await this.state.storage.put(
          `subscription:${clientId}`,
          message.filters
        );
      }
    });

    server.addEventListener('close', () => {
      this.clients.delete(clientId);
    });

    return new Response(null, {
      status: 101,
      webSocket: client
    });
  }

  async broadcastEmail(email) {
    const message = JSON.stringify({
      type: 'new_email',
      data: email
    });

    // 广播给所有订阅的客户端
    for (const [id, socket] of this.clients) {
      try {
        socket.send(message);
      } catch (error) {
        // 连接已断开
        this.clients.delete(id);
      }
    }
  }
}
```
