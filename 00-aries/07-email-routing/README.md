## 服务概述

Cloudflare Email Routing 提供免费的邮件转发服务，可以接收邮件并转发到现有邮箱地址。

### 免费额度
- 邮件处理：每月 5,000 封
- 自定义域名：无限个
- 邮件规则：无限个
- 邮件地址：无限个
- 转发地址：每个地址最多5个

### 主要功能
- **邮件转发** - 接收邮件并转发到指定邮箱
- **自定义地址** - 创建任意@你的域名邮箱
- **通配符支持** - 支持catch-all地址
- **多域名支持** - 管理多个域名的邮件
- **规则引擎** - 灵活的转发规则配置

### 使用场景
- 品牌邮箱（如contact@yourdomain.com）
- 项目专用邮箱（如project@yourdomain.com）
- 临时邮箱地址
- 邮件分类管理
- 域名邮件保护
- 隐私保护（避免暴露真实邮箱）
