## 服务概述

Cloudflare Workers 是无服务器边缘计算平台，在全球250+城市的边缘节点上运行JavaScript/TypeScript代码。

### 免费额度
- 请求次数：每天 100,000 次
- CPU时间：每次请求 10ms
- 内存：128MB
- 脚本大小：25MB

### 适用场景
- API网关
- 请求路由
- 内容转换
- 身份验证
- A/B测试
- 边缘缓存
