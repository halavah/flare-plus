# Workers 快速入门

## 环境准备

### 1. 安装 Wrangler CLI

```bash
# 使用 npm 安装
npm install -g wrangler

# 使用 yarn 安装
yarn global add wrangler

# 使用 pnpm 安装
pnpm add -g wrangler
```

### 2. 登录 Cloudflare

```bash
# 登录账户
wrangler auth login

# 验证登录
wrangler whoami
```

### 3. 获取 API Token（可选）

如果需要 CI/CD 或自动化部署：

1. 访问 [Cloudflare API Tokens](https://dash.cloudflare.com/profile/api-tokens)
2. 创建 Custom Token，权限包括：
   - Zone:Zone:Read
   - Zone:Page Rules:Edit
   - Account:Cloudflare Pages:Edit
   - Account:Account Settings:Read
   - User:User Details:Read
   - Zone:Zone Settings:Edit
   - Zone:Web Application Firewall:Edit

```bash
# 设置环境变量
export CLOUDFLARE_API_TOKEN=your_token_here

# 或使用 wrangler.toml 配置
wrangler auth whoami
```

## 创建第一个 Worker

### 方法一：使用模板

```bash
# 列出可用模板
wrangler generate --list-templates

# 创建基于模板的项目
wrangler generate my-worker https://github.com/cloudflare/worker-template

# 进入项目目录
cd my-worker
```

### 方法二：从头创建

```bash
# 创建新项目
mkdir my-worker
cd my-worker

# 初始化项目
npm init -y

# 安装依赖
npm install wrangler -D

# 创建 wrangler.toml
npx wrangler init
```

### wrangler.toml 配置

```toml
name = "my-worker"
main = "src/index.js"
compatibility_date = "2023-12-01"

# 可选：绑定域名
# [env.production]
# routes = [
#   { pattern = "example.com/*", zone_name = "example.com" }
# ]

# 可选：环境变量
# [vars]
# API_KEY = "your-api-key"

# 可选：KV 命名空间
# [[kv_namespaces]]
# binding = "MY_KV_NAMESPACE"
# id = "your-kv-namespace-id"
```

## 编写 Worker 代码

### 基础响应 Worker

```javascript
// src/index.js
export default {
  async fetch(request, env, ctx) {
    // 获取请求信息
    const url = new URL(request.url);
    const path = url.pathname;

    // 根据路径返回不同内容
    switch (path) {
      case '/':
        return new Response('Hello World!', {
          status: 200,
          headers: { 'Content-Type': 'text/plain' }
        });

      case '/json':
        return new Response(
          JSON.stringify({ message: 'Hello from Worker!' }),
          {
            status: 200,
            headers: { 'Content-Type': 'application/json' }
          }
        );

      case '/time':
        return new Response(
          JSON.stringify({
            time: new Date().toISOString(),
            timezone: Intl.DateTimeFormat().resolvedOptions().timeZone
          }),
          {
            status: 200,
            headers: { 'Content-Type': 'application/json' }
          }
        );

      default:
        return new Response('Not Found', { status: 404 });
    }
  }
};
```

### 请求转发 Worker

```javascript
// 代理 API 请求，添加自定义头部
export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);

    // 转发到后端 API
    if (url.pathname.startsWith('/api/')) {
      const backendUrl = 'https://api.example.com' + url.pathname;

      // 创建新请求
      const backendRequest = new Request(backendUrl, {
        method: request.method,
        headers: request.headers,
        body: request.body,
        redirect: 'follow'
      });

      // 添加自定义头部
      backendRequest.headers.set('X-Forwarded-By', 'Cloudflare Worker');
      backendRequest.headers.set('X-Request-ID', crypto.randomUUID());

      // 发送请求
      const response = await fetch(backendRequest);

      // 可以修改响应
      const modifiedResponse = new Response(response.body, response);
      modifiedResponse.headers.set('X-Response-Modified', 'true');

      return modifiedResponse;
    }

    return new Response('Please use /api/ endpoints', { status: 400 });
  }
};
```

### 调试技巧

```javascript
// 使用 console.log 调试
export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    console.log('Request URL:', url.href);
    console.log('Request method:', request.method);

    // 输出请求头
```

## 部署到 Cloudflare

### 部署到 Workers.dev

```bash
# 部署到默认环境
wrangler publish

# 部署到特定环境
wrangler publish --env production

# 使用自定义 Workers.dev 子域名
# wrangler.toml 中配置:
# name = "my-worker"
# workers_dev = true
```

### 部署到自定义域名

```bash
# 方法1: 通过 wrangler.toml 配置
# [env.production]
# routes = [
#   { pattern = "api.example.com/*", zone_name = "example.com" }
# ]

# 方法2: 通过 CLI 添加
wrangler route list example.com
wrangler route create api.example.com/* --zone-id your-zone-id

# 部署
wrangler publish
```

## 高级功能快速预览

### 使用环境变量

```javascript
// wrangler.toml
[vars]
API_KEY = "your-api-key"
ENVIRONMENT = "production"

// 代码中访问
export default {
  async fetch(request, env, ctx) {
    console.log(env.API_KEY); // 输出: your-api-key
    console.log(env.ENVIRONMENT); // 输出: production

    return new Response('Environment variables loaded');
  }
};
```

### 使用 KV 存储

```javascript
// 绑定 KV 命名空间
// wrangler.toml
# [[kv_namespaces]]
# binding = "MY_KV"
# id = "your-kv-namespace-id"

export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);

    if (url.pathname === '/set') {
      // 写入 KV
      await env.MY_KV.put('key', 'value');
      return new Response('Value stored');
    }

    if (url.pathname === '/get') {
      // 读取 KV
      const value = await env.MY_KV.get('key');
      return new Response(`Value: ${value}`);
    }

    return new Response('Use /set or /get');
  }
};
```

## 常见问题解决

### 1. 内存不足
```javascript
// 使用流式处理大文件
export default {
  async fetch(request) {
    const response = await fetch('https://example.com/large-file.json');
    return new Response(response.body);
  }
};
```

### 2. CPU 时间超限
```javascript
// 使用 event.waitUntil 处理后台任务
export default {
  async fetch(request, env, ctx) {
    // 快速响应
    const response = new Response('Processing started');

    // 后台处理
    ctx.waitUntil(
      fetch('https://api.example.com/process', { method: 'POST' })
    );

    return response;
  }
};
```

### 3. CORS 处理
```javascript
export default {
  async fetch(request) {
    // 处理预检请求
    if (request.method === 'OPTIONS') {
      return new Response(null, {
        headers: {
          'Access-Control-Allow-Origin': '*',
          'Access-Control-Allow-Methods': 'GET, POST, PUT, DELETE',
          'Access-Control-Allow-Headers': 'Content-Type',
        },
      });
    }

    // 处理实际请求
    const response = await handleRequest(request);

    // 添加 CORS 头
    response.headers.set('Access-Control-Allow-Origin', '*');
    return response;
  }
};
```
