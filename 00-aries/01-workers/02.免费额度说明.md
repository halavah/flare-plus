## 详细说明

### 1. 请求次数

**定义**：每次触发 Worker 执行计为一次请求

**包含场景**：
- HTTP/HTTPS 请求
- 调度任务（Cron Triggers）
- Workers 之间的内部调用

**不包含场景**：
- CDN 缓存命中（直接返回，不触发 Worker）
- 纯静态资源请求

**额度计算**：
- **UTC 时间**：每天 00:00:00 重置
- **全球统计**：所有地区共享额度
- **实时监控**：Dashboard 可查看实时用量

### 2. CPU 时间

**定义**：Worker 代码实际执行时间

**时间限制**：
- **免费版**：每次请求最多 10ms
- **付费版**：每次请求最多 50ms
- **超时处理**：超时后自动终止

**优化技巧**：
```javascript
// ❌ 低效 - 同步操作
const data = await fetch('https://api.example.com/data');
const processed = heavySyncProcess(data);

// ✅ 高效 - 异步操作，减少 CPU 占用
const data = await fetch('https://api.example.com/data');
event.waitUntil(heavyAsyncProcess(data));
```

### 3. 内存限制

**分配量**：128MB 每个请求

**包含内容**：
- 代码占用
- 变量存储
- 堆栈空间

**内存管理**：
```javascript
// ✅ 避免内存泄漏
let cache = new Map();

// 定期清理
if (cache.size > 1000) {
  cache.clear();
}

// ✅ 及时释放大对象
function processLargeData() {
  const largeObject = fetchLargeData();
  const result = process(largeObject);
  // largeObject 自动 GC
  return result;
}
```

## 成本优化策略

### 1. 缓存策略
```javascript
// 利用 Cloudflare Cache 减少请求
addEventListener('fetch', event => {
  const cacheKey = new Request(event.request.url);

  event.respondWith(
    caches.open('my-cache').then(cache => {
      return cache.match(cacheKey) || fetchAndCache(event.request);
    })
  );
});
```

### 2. CPU 优化
```javascript
// 使用 WebAssembly 处理密集计算
import { process } from './wasm-module';

addEventListener('fetch', event => {
  // WASM 模块通常比 JS 更快
  const result = process(event.request);
});
```

### 3. 批量处理
```javascript
// 批量减少请求数量
addEventListener('scheduled', event => {
  // 定时任务批量处理
  processBatch();
});
```

## 免费额度过后的处理

### 1. 自动暂停
- 超出额度后 Worker 自动暂停
- 请求返回 403 Forbidden
- 第二天自动恢复

### 2. 升级方案
- **Pro Plan**：$5/月
  - 1000万请求/月
  - 每请求 50ms CPU
- **Business Plan**：$200/月
  - 无限请求
  - 高级功能

### 3. 预警设置
```javascript
// 使用环境变量设置配额监控
const QUOTA_WARNING = Number(env.QUOTA_WARNING) || 90000;

addEventListener('fetch', event => {
  const requests = incrementCounter('requests');
  if (requests > QUOTA_WARNING) {
    // 发送预警
    sendAlert(' approaching quota limit');
  }
});
```

## 最佳实践

### 1. 请求优化
- 使用缓存减少不必要请求
- 合并多个请求为批量操作
- 实施请求去重

### 2. CPU 优化
- 避免同步阻塞操作
- 使用事件循环处理异步任务
- 预计算常用结果

### 3. 内存优化
- 及时释放大对象
- 避免内存泄漏
- 使用流式处理大文件

### 4. 架构设计
- 将复杂逻辑拆分为多个简单 Worker
- 利用 D1/R2/KV 存储共享数据
- 使用 Webhook 减少轮询
