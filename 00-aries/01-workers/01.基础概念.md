# Workers 基础概念

## 什么是 Cloudflare Workers

Cloudflare Workers 是 Cloudflare 的无服务器计算平台，允许开发者在 Cloudflare 的全球边缘网络上运行 JavaScript/TypeScript 代码。这些代码运行在离用户最近的数据中心，提供极低的延迟。

## 核心架构

### V8 Isolates
- **隔离环境**：每个 Worker 运行在独立的 V8 isolate 中
- **安全隔离**：相互之间完全隔离，不会互相影响
- **冷启动**：无服务器特性，按需启动
- **资源限制**：CPU、内存有严格限制

### Edge Network
- **全球分布**：250+ 城市的边缘节点
- **智能路由**：自动路由到最近的节点
- **Anycast IP**：同一 IP 地址全球访问
- **缓存集成**：与 Cloudflare CDN 深度集成

## 运行模型

### 请求处理流程
1. **用户请求** → 到达最近的 Cloudflare 边缘节点
2. **Worker 执行** → JavaScript/TypeScript 代码处理
3. **响应返回** → 直接返回给用户

### 执行环境
- **JavaScript ES2022**：支持现代 JavaScript 特性
- **Web APIs**：Fetch API、URL API、Streams API 等
- **Node.js APIs**：部分 Node.js 兼容
- **WebAssembly**：支持 WASM 模块

## 关键特性

### 1. 边缘计算
```javascript
// 示例：基于地理位置的响应
addEventListener('fetch', event => {
  const country = event.request.cf.country;
  if (country === 'CN') {
    event.respondWith(handleChinaRequest(event.request));
  } else {
    event.respondWith(handleGlobalRequest(event.request));
  }
});
```

### 2. 无服务器
- **无需管理服务器**：完全托管服务
- **自动扩缩容**：根据请求量自动调整
- **按使用付费**：只支付实际使用的资源

### 3. 低延迟
- **0ms 冷启动**：V8 isolate 预热
- **毫秒级响应**：本地执行，无回源延迟
- **全球部署**：代码全球同步

## Workers 与传统后端的区别

| 特性 | Workers | 传统后端 |
|------|---------|----------|
| 部署位置 | 全球边缘 | 特定地区 |
| 冷启动 | 0ms | 秒级 |
| 扩缩容 | 自动 | 手动配置 |
| 状态管理 | 无状态（配合 KV/R2/D1） | 有状态 |
| 运维 | 无需运维 | 需要运维 |

## 限制说明

### 执行限制
- **CPU 时间**：每次请求 10ms（免费版）
- **内存**：128MB
- **请求大小**：100MB
- **响应大小**：100MB

### 功能限制
- **不支持**：文件系统访问
- **不支持**：原生 TCP/UDP 套接字
- **有限制**：某些 Web APIs
