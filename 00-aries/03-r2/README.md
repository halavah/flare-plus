## 服务概述

Cloudflare R2 是兼容S3 API的对象存储服务，最大的优势是免费出口流量。

### 免费额度
- 存储：每月 10GB
- Class A操作：每月 1,000,000 次（PUT、COPY）
- Class B操作：每月 10,000,000 次（GET、LIST）
- 出口流量：免费（相比S3节省$90/TB）
- 数据读取请求：每GB 10,000次
- 数据写入请求：每GB 1,000次

### 主要特点
- 100% S3兼容
- 无出口流量费用
- 全球分布式
- 支持CDN集成
- 数据持久性99.999999999%
