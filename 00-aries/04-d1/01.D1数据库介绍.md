# D1 数据库介绍

## D1 概述

Cloudflare D1 是基于 SQLite 的分布式数据库服务，构建在 Cloudflare 全球网络边缘，提供低延迟的数据访问和强大的查询能力。

## 核心特性

### 1. SQLite 兼容性
```javascript
// 标准 SQLite 语法
SELECT * FROM users WHERE id = ?;
INSERT INTO posts (title, content) VALUES (?, ?);

// 支持复杂查询
SELECT u.*, COUNT(p.id) as post_count
FROM users u
LEFT JOIN posts p ON u.id = p.user_id
GROUP BY u.id
HAVING post_count > 5
ORDER BY post_count DESC;
```

### 2. 全球分布
```javascript
// 数据位置
- 数据存储在 Cloudflare 边缘位置
- 自动复制到全球 POP（Points of Presence）
- 就近读取，减少延迟

// 查询路由
- 读查询路由到最近的数据副本
- 写查询路由到主数据节点
- 最终一致性保证
```

### 3. 无服务器架构
```javascript
// 特点
✅ 无需管理服务器
✅ 自动扩缩容
✅ 按使用计费
✅ 内置备份
✅ 高可用性

// 集成方式
- Workers 直接访问
- Pages Functions 集成
- REST API 接口
```

## 数据库架构

### 1. 存储引擎
```javascript
// 基于 SQLite 3.39+
- ACID 事务支持
- WAL (Write-Ahead Logging) 模式
- 并发控制
- 崩溃恢复

// 扩展功能
- JSON 扩展
- FTS (Full-Text Search)
- RTREE 索引
- 数学函数
```

### 2. 复制机制
```javascript
// 多层复制
Primary Node (主节点)
├── Regional Replicas (区域副本)
│   ├── North America
│   ├── Europe
│   └── Asia
└── Edge Caches (边缘缓存)
    ├── CDN Level 1
    ├── CDN Level 2
    └── CDN Level 3

// 数据流
写入请求 → Primary Node
├── 立即确认
├── 异步复制到区域副本
└── 缓存更新

读取请求 → 最近副本
├── 边缘缓存命中
├── 区域副本读取
└── 主节点回退
```

### 3. 查询优化器
```javascript
// 智能查询路由
function routeQuery(query) {
  if (isReadOnlyQuery(query)) {
    return routeToNearestReplica(query);
  } else {
    return routeToPrimaryNode(query);
  }
}

// 缓存策略
- SELECT 查询结果缓存
- 预计算结果
- 查询计划缓存
```

## 数据类型

### 1. 基础类型
```sql
-- 数值类型
INTEGER      -- 整数
REAL         -- 浮点数
NUMERIC      -- 数字存储类
BLOB         -- 二进制数据

-- 文本类型
TEXT         -- 文本字符串

-- 特殊类型
ANY          -- 动态类型
```

### 2. 日期时间
```sql
-- 日期函数
CURRENT_DATE     -- 当前日期
CURRENT_TIME     -- 当前时间
CURRENT_TIMESTAMP -- 当前时间戳

-- 示例
CREATE TABLE events (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  scheduled_date DATE,
  event_time TIME
);

-- 查询示例
SELECT * FROM events
WHERE created_at > datetime('now', '-7 days')
  AND scheduled_date >= date('now');
```

### 3. JSON 数据
```sql
-- JSON 扩展
CREATE TABLE products (
  id INTEGER PRIMARY KEY,
  name TEXT,
  metadata JSON
);

-- 插入 JSON
INSERT INTO products (name, metadata)
VALUES ('Laptop', json('{"brand": "Apple", "specs": {"ram": "16GB", "storage": "512GB"}}'));

-- 查询 JSON
SELECT
  name,
  json_extract(metadata, '$.brand') as brand,
  json_extract(metadata, '$.specs.ram') as ram
FROM products;

-- JSON 函数
json_extract(json, path)     -- 提取值
json_array_length(json)      -- 数组长度
json_array_contains(json, value) -- 包含检查
```

## 索引系统

### 1. 基础索引
```sql
-- 创建索引
CREATE INDEX idx_users_email ON users(email);
CREATE UNIQUE INDEX idx_users_username ON users(username);

-- 复合索引
CREATE INDEX idx_posts_author_date ON posts(user_id, created_at);
CREATE INDEX idx_products_category_price ON products(category, price);

-- 删除索引
DROP INDEX idx_users_email;
```

### 2. 特殊索引
```sql
-- 部分索引
CREATE INDEX idx_active_users ON users(id) WHERE status = 'active';

-- 表达式索引
CREATE INDEX idx_users_lower_email ON users(lower(email));

-- JSON 索引
CREATE INDEX idx_product_brand ON products((json_extract(metadata, '$.brand')));
```

### 3. 全文搜索
```sql
-- FTS5 表
CREATE VIRTUAL TABLE posts_fts USING fts5(
  title,
  content,
  content='posts',
  content_rowid='id'
);

-- 全文搜索
SELECT p.*
FROM posts p
JOIN posts_fts fts ON p.id = fts.rowid
WHERE posts_fts MATCH 'search query'
ORDER BY rank;

-- 插入数据
INSERT INTO posts_fts(rowid, title, content)
SELECT id, title, content FROM posts;
```

## 事务管理

### 1. ACID 特性
```sql
-- 自动事务
BEGIN TRANSACTION;
INSERT INTO orders (user_id, total) VALUES (?, ?);
UPDATE inventory SET quantity = quantity - ? WHERE product_id = ?;
COMMIT;

-- 错误处理
BEGIN TRANSACTION;
INSERT INTO orders (user_id, total) VALUES (?, ?);
UPDATE inventory SET quantity = quantity - ? WHERE product_id = ?;
-- 如果出错
ROLLBACK;
```
