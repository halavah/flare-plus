## 服务概述

Cloudflare D1 是基于SQLite的分布式SQL数据库，运行在Cloudflare边缘网络上。

### 免费额度
- 存储空间：5GB
- 数据库数量：每个账户 10 个
- 读取操作：每天 100,000 次
- 写入操作：每天 1,000 次
- 行存储：每个表 1000万行
- 查询执行时间：最大 30秒

### 主要特性
- 基于SQLite 3.39
- RESTful API
- 支持大多数SQL语句
- 事务支持
- 自动备份
- 与Workers紧密集成

### 使用限制
- 不支持用户定义函数
- 不支持JSON扩展
- 最大查询结果 10MB
- 最大单个值 1MB
