# Pages 自定义域名

## 域名配置概述

Cloudflare Pages 允许你轻松绑定自己的域名，提供免费的 SSL 证书、DNS 管理和全球 CDN 加速。

## 域名类型

### 1. 顶级域名 (Apex Domain)
```
example.com
mywebsite.org
company.net
```

### 2. 子域名 (Subdomain)
```
www.example.com
app.example.com
api.example.com
blog.example.com
```

### 3. 通配符域名 (Wildcard)
```
*.example.com  (包含所有子域名)
```

## 配置步骤

### 方法1：通过 Dashboard 配置

#### 步骤详解

1. **登录 Dashboard**
   ```
   访问: https://dash.cloudflare.com/
   路径: Pages → Your Project → Custom domains
   ```

2. **添加自定义域名**
   ```
   1. 点击 "Set up a custom domain"
   2. 输入域名 (如: example.com 或 www.example.com)
   3. 点击 "Continue"
   ```

3. **配置 DNS 记录**
   ```
   # 根域名 (Apex) 配置
   类型: A
   名称: @
   值: 192.0.2.1
   TTL: Auto

   # 子域名配置
   类型: CNAME
   名称: www
   值: your-project.pages.dev
   TTL: Auto
   ```

4. **等待 DNS 传播**
   ```
   - 通常需要 5-15 分钟
   - 最多可能需要 24 小时
   - 可以通过 nslookup 检查
   ```

### 方法2：通过 API 配置

```javascript
// 添加自定义域名
async function addCustomDomain(projectName, domain) {
  const accountId = 'your-account-id';
  const apiToken = 'your-api-token';

  const response = await fetch(
    `https://api.cloudflare.com/client/v4/accounts/${accountId}/pages/projects/${projectName}/domains`,
    {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${apiToken}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        domain_name: domain
      })
    }
  );

  return response.json();
}

// 示例使用
addCustomDomain('my-project', 'www.example.com');
```

## DNS 配置详解

### 根域名 (Apex Domain) 配置

#### 使用 A 记录
```dns
# 传统方式
TYPE: A
NAME: @ (或 example.com)
VALUE: 192.0.2.1  # Cloudflare IP
TTL: 300         # 5分钟 (或 Auto)
```

#### 使用 ANAME/CNAME Flattening (推荐)
```dns
# 现代方式 (如果 DNS 提供商支持)
TYPE: ANAME
NAME: @
VALUE: your-project.pages.dev
TTL: Auto
```

### 子域名配置

```dns
# 推荐：使用 CNAME
TYPE: CNAME
NAME: www
VALUE: your-project.pages.dev
TTL: Auto

# 其他子域名
TYPE: CNAME
NAME: api
VALUE: your-project.pages.dev
TTL: Auto

TYPE: CNAME
NAME: blog
VALUE: your-project.pages.dev
TTL: Auto
```

### 通用 DNS 模板

```dns
; 基础配置
@                IN    A      192.0.2.1
www              IN    CNAME  your-project.pages.dev
*                IN    CNAME  your-project.pages.dev

; 常用服务配置
api              IN    CNAME  your-project.pages.dev
app              IN    CNAME  your-project.pages.dev
docs             IN    CNAME  your-project.pages.dev
blog             IN    CNAME  your-project.pages.dev
staging          IN    CNAME  your-project.pages.dev
dev              IN    CNAME  your-project.pages.dev
```

```dns

1. 登录 GoDaddy DNS 管理页面
2. 添加记录:
   - Type: A
   - Name: @
   - Value: 192.0.2.1
   - TTL: 1 Hour

   - Type: CNAME
   - Name: www
   - Value: your-project.pages.dev
```

### 3. Namecheap

```dns
# Namecheap 高级 DNS
1. 登录 Namecheap
2. 进入域名的 Advanced DNS
3. 添加记录:

# 根域名
Host Record: @
TTL: Automatic
Type: A
Value: 192.0.2.1

# www 子域名
Host Record: www
TTL: Automatic
Type: CNAME
Value: your-project.pages.dev
```

### 4. Route 53 (AWS)

```json
{
  "Comment": "Add custom domain for Cloudflare Pages",
  "Changes": [
    {
      "Action": "CREATE",
      "ResourceRecordSet": {
        "Name": "example.com",
        "Type": "A",
        "TTL": 300,
        "ResourceRecords": [{ "Value": "192.0.2.1" }]
      }
    },
    {
      "Action": "CREATE",
      "ResourceRecordSet": {
        "Name": "www.example.com",
        "Type": "CNAME",
        "TTL": 300,
        "ResourceRecords": [{ "Value": "your-project.pages.dev" }]
      }
    }
  ]
}
```

## 重定向配置

### HTTP 到 HTTPS 重定向

```javascript
// 自动重定向
Cloudflare 自动将 HTTP 重定向到 HTTPS

# 也可以手动配置
# 在 Functions 中添加
export default {
  async fetch(request) {
    const url = new URL(request.url);

    if (url.protocol === 'http:') {
      url.protocol = 'https';
      return Response.redirect(url, 301);
    }

    // 继续处理请求...
  }
};
```

### WWW 到非 WWW 重定向

```javascript
// Page Rules 配置
1. Dashboard → Rules → Page Rules
2. 添加规则:
   URL: www.example.com/*
   设置: Forwarding URL
   301 - 永久重定向
   https://example.com/$1

# 或使用 Functions
export default {
  async fetch(request) {
    const url = new URL(request.url);

    if (url.hostname === 'www.example.com') {
      url.hostname = 'example.com';
      return Response.redirect(url, 301);
    }

    // 继续处理...
  }
};
```

## 故障排除

### 常见问题及解决方案

#### 1. DNS 解析失败

```javascript
// 诊断命令
nslookup example.com
dig example.com
ping example.com

# 解决方案
1. 检查 DNS 记录
2. 等待 DNS 传播 (最多24小时)
3. 清除本地 DNS 缓存
4. 使用公共 DNS (8.8.8.8)
```

#### 2. SSL 证书错误

```javascript
// 检查工具
1. SSL Labs SSL Test
2. curl -I https://example.com
3. 浏览器开发者工具

# 解决方案
1. 检查 DNS 记录
2. 等待证书颁发
3. 检查加密模式
4. 清除浏览器缓存
```

#### 3. 重定向循环

```javascript
// 问题诊断
1. 检查 Page Rules
2. 检查 Functions 代码
3. 检查 .htaccess (如果存在)

# 解决方案
1. 移除冲突的重定向
2. 使用正确的重定向代码
3. 测试重定向链
```
