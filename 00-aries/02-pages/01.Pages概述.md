# Pages 概述

## 什么是 Cloudflare Pages

Cloudflare Pages 是 Cloudflare 提供的全栈平台，专门用于构建和部署现代化的网站和应用程序。它结合了 Jamstack 架构的优势与 Cloudflare 的全球边缘网络。

## 核心特性

### 1. 全球 CDN 加速
- **250+ 边缘节点** - 全球覆盖，自动将网站部署到离用户最近的位置
- **智能缓存** - 自动优化内容缓存策略
- **HTTP/3 支持** - 最新的网络协议，提升加载速度

### 2. Git 工作流集成
- **自动部署** - 推送代码自动触发构建和部署
- **预览部署** - 每个 Pull Request 自动生成预览链接
- **分支管理** - 支持多分支部署，开发、测试、生产环境分离

### 3. 构建系统
- **灵活构建** - 支持所有主流静态站点生成器
- **自定义构建** - 自定义构建命令和输出目录
- **并行构建** - 加速构建过程

### 4. 函数集成
- **Workers Functions** - 无需服务器即可运行后端逻辑
- **边缘计算** - 在全球边缘节点执行函数
- **全栈应用** - 前后端统一部署

## 工作原理

### 构建流程

```
Git Push → Webhook → Build → Deploy → Global CDN
    ↓         ↓        ↓        ↓
  代码提交   触发构建   生成静态   全球部署
           检测变更   资源文件   节点同步
```

## 免费版功能

### 核心功能
- **无限带宽** - 无限制的流量传输
- **无限请求** - 无限制的页面访问次数
- **无限项目** - 部署任意数量的网站
- **自定义域名** - 绑定自己的域名
- **SSL/TLS** - 免费的 SSL 证书

### 构建限制
- **每月构建次数**: 500 次
- **并发构建**: 最多 5 个
- **单次构建时间**: 最多 25 分钟
- **存储空间**: 无限制

### Workers Functions
- **请求次数**: 每天 100,000 次
- **CPU 时间**: 每次请求 10ms
- **内存**: 128MB

## 支持的框架和工具

### 静态站点生成器 (SSG)

| 框架 | 支持程度 | 特殊配置 |
|------|----------|----------|
| **Next.js** | 完全支持 | 输出模式配置 |
| **Nuxt.js** | 完全支持 | Nitro 模式 |
| **Gatsby** | 原生支持 | 无需额外配置 |
| **Astro** | 完全支持 | 构建输出适配 |
| **Hugo** | 原生支持 | 配置输出目录 |
| **Jekyll** | 原生支持 | Ruby 环境 |
| **Eleventy** | 原生支持 | Node.js 环境 |

### 前端框架

```javascript
// 支持 React, Vue, Angular, Svelte 等
// 示例：React 应用配置
// wrangler.toml
name = "my-react-app"
compatibility_date = "2023-12-01"

[build]
command = "npm run build"
publish = "dist"
```

### 构建工具

```javascript
// Vite 配置示例
// vite.config.js
export default {
  build: {
    outDir: 'dist',
    assetsDir: 'assets',
    sourcemap: true
  },
  base: process.env.CF_PAGES ? '/' : '/'
}
```

## 项目结构

### 标准项目结构

```
my-pages-project/
├── .gitignore
├── package.json
├── wrangler.toml
├── functions/
│   └── api/
│       └── [[path]].js    # Workers Functions
├── public/                # 静态资源
│   ├── images/
│   ├── fonts/
│   └── favicon.ico
├── src/                   # 源代码
│   ├── components/
│   ├── pages/
│   ├── styles/
│   └── index.js
└── dist/                  # 构建输出
```

### Functions 目录结构

```
functions/
├── api/
│   ├── users/
│   │   ├── [id].js        # 动态路由
│   │   └── index.js       # /api/users
│   └── auth.js           # /api/auth
├── middleware/
│   ├── auth.js           # 认证中间件
│   └── cors.js           # CORS 处理
└── [[path]].js           # 404 和通用路由
```
