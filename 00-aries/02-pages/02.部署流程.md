# Pages 部署流程

## 快速开始

### 1. 连接 Git 仓库

#### 支持 Git 提供商
- **GitHub** - 最流行的选择，完全集成
- **GitLab** - 自托管和云版本都支持
- **Bitbucket** - Atlassian 生态系统

#### 步骤说明

1. **登录 Cloudflare Dashboard**
   ```
   访问: https://dash.cloudflare.com/
   路径: Pages → Create a project
   ```

2. **选择连接方式**
   - **连接到 Git** - 推荐方式，自动 CI/CD
   - **上传资产** - 简单静态网站
   - **使用模板** - 快速开始

3. **授权 Git 访问**
   ```bash
   # GitHub 授权示例
   # 1. 点击 "Connect to Git"
   # 2. 选择 GitHub
   # 3. 授权 Cloudflare 访问
   # 4. 选择仓库
   ```

```javascript
// package.json 构建脚本
{
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview",

    "pages:deploy": "wrangler pages deploy dist"

        }

    }
  },
  server: {
    port: 3000
  }
}
```

## 部署策略

### 1. 自动部署（推荐）

#### 配置自动触发
```javascript
// .github/workflows/pages.yml
name: Deploy to Cloudflare Pages

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      deployments: write

    steps:
      - name: Checkout
        uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build

      - name: Deploy to Cloudflare Pages
        uses: cloudflare/pages-action@v1
        with:
          apiToken: ${{ secrets.CLOUDFLARE_API_TOKEN }}
          accountId: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
          projectName: my-pages-project
          directory: dist
```

#### 分支部署策略
```javascript
// 分支映射
main → production
dev → staging
feature/* → preview

// 配置示例
// Dashboard → Pages → Settings → Branches

Production branch: main
Preview branches: dev, test
Custom domains per branch:
  - main: example.com
  - dev: dev.example.com
```

### 2. 手动部署

#### 使用 Wrangler CLI
```bash
# 安装 Wrangler
npm install -g wrangler

# 登录
wrangler login

# 部署生产版本
wrangler pages deploy dist --project-name=my-project

# 部署到特定分支
wrangler pages deploy dist --project-name=my-project --branch=staging

# 使用自定义域名
wrangler pages deploy dist --project-name=my-project --compatibility-date=2023-12-01
```

#### 使用 API
```javascript
// 部署脚本
async function deployToPages() {
  const accountId = 'your-account-id';
  const projectName = 'my-project';
  const apiToken = 'your-api-token';

  // 1. 创建部署
  const deployment = await fetch(
    `https://api.cloudflare.com/client/v4/accounts/${accountId}/pages/projects/${projectName}/deployments`,
    {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${apiToken}`,
        'Content-Type': 'application/json'
      }
    }
  );

  // 2. 上传文件
  // ... 文件上传逻辑

  // 3. 等待部署完成
  const result = await deployment.json();
  return result;
}
```

## 域名和 SSL

### 1. 添加自定义域名

#### Dashboard 配置
```
1. Pages → your-project → Custom domains
2. Add custom domain
3. 输入域名: example.com
4. 配置 DNS 记录
```

#### DNS 记录
```dns
# A 记录 (如果是根域名)
example.com.    IN    A    192.0.2.1

# CNAME 记录 (如果是子域名)
www.example.com. IN   CNAME  your-project.pages.dev.

# 推荐使用 CNAME 扁平化
www.example.com. IN   CNAME  your-project.pages.dev.
```

### 2. SSL 证书

#### 自动颁发

## 故障排除

### 常见问题

1. **构建失败**
   - 检查构建命令
   - 验证依赖版本
   - 查看构建日志

2. **404 错误**
   - 检查输出目录
   - 验证路由配置
   - 确认文件存在

3. **样式丢失**
   - 检查资源路径
   - 验证 base 配置
   - 确认构建输出
