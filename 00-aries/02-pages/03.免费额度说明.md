# Pages 免费额度说明

## 免费套餐概览

Cloudflare Pages 提供非常慷慨的免费套餐，适合个人项目、开源项目和中小型企业。

### 核心免费功能

| 功能 | 免费额度 | 说明 |
|------|----------|------|
| **托管网站** | 无限制 | 部署任意数量的网站 |
| **带宽** | 无限制 | 无限制的流量传输 |
| **请求次数** | 无限制 | 无限制的页面访问 |
| **存储空间** | 无限制 | 网站文件大小无限制 |
| **自定义域名** | 无限制 | 绑定自己的域名 |
| **SSL/TLS** | 免费 | 自动颁发和管理证书 |

### 构建相关额度

| 功能 | 免费额度 | 超额说明 |
|------|----------|----------|
| **月度构建次数** | 500次 | 超出后停止构建，下月重置 |
| **并发构建** | 5个 | 同时进行的构建数量 |
| **单次构建时间** | 25分钟 | 超时自动取消 |
| **Workers Functions** | 共享 Workers 额度 | 每天10万请求 |
| **带宽** | 100GB/月 | 包含在免费套餐内 |

#### 使用场景示例
```javascript
// 计算使用量
假设你的网站有：
- 10,000 日访问
- 20% 需要 Workers 处理
- 平均每个访问 2 次请求

计算：
10,000 × 0.2 × 2 = 4,000 次请求/天
4,000 × 30 = 120,000 次请求/月

结论：
免费额度可能不够，需要考虑升级
```

## 常见问题

### Q: 构建次数用完了怎么办？

A:
- 等待下个月重置
- 手动删除旧部署
- 升级到付费计划
- 优化 Git 工作流

### Q: Workers 请求超限怎么处理？

A:
- 优化代码减少调用
- 使用缓存减少请求
- 升级到付费计划
- 使用独立 Workers

### Q: 可以同时部署多个项目吗？

A:
- 完全免费
- 无项目数量限制
- 每个项目独立计算

### Q: 带宽真的无限制吗？

A:
- 正常使用无限制
- 禁止滥用
- 遵守服务条款
- 超大用量可能被限制
