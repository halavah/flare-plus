## 服务概述

Cloudflare Pages 是全栈静态网站托管平台，支持直接从Git仓库自动构建和部署。

### 免费额度
- 静态网站托管：无限
- 带宽：每月 100GB
- 构建次数：每月 500 次
- 并发构建：最多 5 个
- Functions：与Workers免费额度共享

### 支持的框架
- React, Vue, Angular
- Next.js, Nuxt.js
- Gatsby, Astro
- Hugo, Jekyll
- 任何静态站点生成器
