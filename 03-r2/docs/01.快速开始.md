## 项目简介

**03-r2** 是 Cloudflare R2 对象存储的完整 API 实现，提供类似 AWS S3 的对象存储服务，但零出站费用。

### 核心特性

- ✅ 完整的对象 CRUD 操作
- ✅ 元数据管理
- ✅ 预签名 URL（临时访问链接）
- ✅ 多部分上传（大文件上传）
- ✅ 批量操作
- ✅ 存储统计
- ✅ CORS 支持
- ✅ 完整的错误处理

## 环境准备

### 1. 安装依赖

```bash
cd 03-r2
npm install
```

### 2. 创建 R2 存储桶

```bash
# 使用 Wrangler 创建存储桶
wrangler r2 bucket create flare-plus-storage

# 列出所有存储桶
wrangler r2 bucket list
```

### 3. 配置 wrangler.toml

确保 `wrangler.toml` 中的 R2 绑定配置正确：

```toml
[[r2_buckets]]
binding = "MY_BUCKET"
bucket_name = "flare-plus-storage"
```

## API 使用示例

### 1. 上传文件

#### 简单上传（小文件）

```bash
curl -X POST http://localhost:8787/api/objects \
  -H "Content-Type: application/json" \
  -d '{
    "key": "documents/hello.txt",
    "value": "Hello, Cloudflare R2!",
    "contentType": "text/plain"
  }'
```

响应：

```json
{
  "success": true,
  "key": "documents/hello.txt",
  "size": 22,
  "etag": "abc123...",
  "uploaded": true
}
```

#### 上传二进制文件

```bash
curl -X POST http://localhost:8787/api/objects \
  -F "key=images/photo.jpg" \
  -F "file=@/path/to/photo.jpg"
```

### 2. 下载文件

```bash
# 获取文件内容
curl http://localhost:8787/api/objects/documents/hello.txt

# 下载文件
curl -O http://localhost:8787/api/objects/images/photo.jpg
```

### 3. 列出文件

```bash
# 列出所有文件
curl http://localhost:8787/api/objects

# 按前缀列出
curl http://localhost:8787/api/objects?prefix=documents/

# 分页列出
curl http://localhost:8787/api/objects?limit=10&cursor=abc123
```

响应：

```json
{
  "success": true,
  "objects": [
    {
      "key": "documents/hello.txt",
      "size": 22,
      "uploaded": "2024-01-15T10:00:00.000Z",
      "httpEtag": "abc123..."
    }
  ],
  "truncated": false,
  "cursor": null
}
```

### 4. 删除文件

```bash
curl -X DELETE http://localhost:8787/api/objects/documents/hello.txt
```

响应：

```json
{
  "success": true,
  "key": "documents/hello.txt",
  "deleted": true
}
```

### 5. 元数据管理

#### 获取元数据

```bash
curl http://localhost:8787/api/objects/documents/hello.txt/metadata
```

响应：

```json
{
  "success": true,
  "key": "documents/hello.txt",
  "size": 22,
  "uploaded": "2024-01-15T10:00:00.000Z",
```

#### 更新元数据

```bash
curl -X PUT http://localhost:8787/api/objects/documents/hello.txt/metadata \
  -H "Content-Type: application/json" \
  -d '{
    "httpMetadata": {
      "contentType": "text/plain",
      "contentLanguage": "zh-CN"
    },

      "author": "张三",
```

### 6. 预签名 URL

生成临时访问链接：

```bash
curl -X POST http://localhost:8787/api/objects/documents/hello.txt/presigned \
  -H "Content-Type: application/json" \
  -d '{
    "expiresIn": 3600,
    "action": "read"
  }'
```

响应：

```json
{
  "success": true,
  "url": "https://...",
  "expiresAt": "2024-01-15T11:00:00.000Z"
}
```

### 7. 批量操作

#### 批量上传

```bash
curl -X POST http://localhost:8787/api/objects/batch \
  -H "Content-Type: application/json" \
```

```bash
  -d '{
    "action": "delete",
    "keys": [
```

## 进阶功能

### 1. 多部分上传（大文件）

适用于 > 100MB 的大文件：

#### 步骤 1: 创建多部分上传

```bash
curl -X POST http://localhost:8787/api/objects/large-file.zip/multipart \
  -H "Content-Type: application/json" \
  -d '{
    "action": "create"
  }'
```

响应：

```json
{
  "success": true,
  "key": "large-file.zip",
  "uploadId": "upload-123456"
}
```

#### 步骤 2: 上传分块

```bash
# 上传第 1 块
curl -X POST http://localhost:8787/api/objects/large-file.zip/multipart \
  -H "Content-Type: application/json" \
  -d '{
    "action": "uploadPart",
    "uploadId": "upload-123456",
    "partNumber": 1,
    "data": "<base64-encoded-data>"
  }'

# 上传第 2 块
curl -X POST http://localhost:8787/api/objects/large-file.zip/multipart \
  -H "Content-Type: application/json" \
  -d '{
    "action": "uploadPart",
    "uploadId": "upload-123456",
    "partNumber": 2,
    "data": "<base64-encoded-data>"
  }'
```

#### 步骤 3: 完成上传

```bash
curl -X POST http://localhost:8787/api/objects/large-file.zip/multipart \
  -H "Content-Type: application/json" \
  -d '{
    "action": "complete",
    "uploadId": "upload-123456",
    "parts": [
      {"partNumber": 1, "etag": "etag1"},
      {"partNumber": 2, "etag": "etag2"}
    ]
  }'
```

### 2. 前端集成示例

#### HTML + JavaScript

```html
<!DOCTYPE html>
<html>
<head>
  <title>R2 文件上传</title>
</head>
<body>
  <h1>文件上传到 R2</h1>
  <input type="file" id="fileInput">
  <button onclick="uploadFile()">上传</button>
  <div id="status"></div>

  <script>
    const API_URL = 'http://localhost:8787';

    async function uploadFile() {
      const fileInput = document.getElementById('fileInput');
      const file = fileInput.files[0];

      if (!file) {
        alert('请选择文件');
        return;
      }

      const reader = new FileReader();

      reader.onload = async (e) => {
        const content = e.target.result;

        const response = await fetch(`${API_URL}/api/objects`, {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json'
          },
          body: JSON.stringify({
            key: `uploads/${file.name}`,
            value: btoa(content), // Base64 编码
            contentType: file.type
          })
        });

        const result = await response.json();

        if (result.success) {
          document.getElementById('status').textContent = '上传成功！';
        } else {
          document.getElementById('status').textContent = '上传失败：' + result.error;
        }
      };

      reader.readAsBinaryString(file);
    }
  </script>
</body>
</html>
```

#### React 组件

```jsx
import { useState } from 'react';

function R2FileUpload() {
  const [file, setFile] = useState(null);
  const [uploading, setUploading] = useState(false);
  const [status, setStatus] = useState('');

  const handleUpload = async () => {
    if (!file) return;

    setUploading(true);
    setStatus('上传中...');

    try {
      const formData = new FormData();
      formData.append('key', `uploads/${file.name}`);
      formData.append('file', file);

      const response = await fetch('http://localhost:8787/api/objects', {
        method: 'POST',
        body: formData
      });

      const result = await response.json();

      if (result.success) {
        setStatus('上传成功！');
      } else {
        setStatus('上传失败：' + result.error);
      }
    } catch (error) {
      setStatus('上传错误：' + error.message);
    } finally {
      setUploading(false);
    }
  };

  return (
    <div>
      <h2>上传文件到 R2</h2>
      <input
        type="file"
        onChange={(e) => setFile(e.target.files[0])}
        disabled={uploading}
      />
      <button onClick={handleUpload} disabled={uploading || !file}>
        {uploading ? '上传中...' : '上传'}
      </button>
      {status && <p>{status}</p>}
    </div>
  );
}

export default R2FileUpload;
```

## 常见问题

### 1. R2 与 S3 有什么区别？

- **零出站费用**：R2 不收取数据传出费用
- **API 兼容**：兼容 AWS S3 API
- **全球分发**：自动全球复制
- **价格优势**：存储成本更低

### 2. 免费额度是多少？

- 存储：10 GB
- A 类操作（写入）：100 万次/月
- B 类操作（读取）：1000 万次/月

### 3. 如何处理大文件？

使用多部分上传，将文件分块上传，支持断点续传。

### 4. 如何设置 CORS？

在 `wrangler.toml` 中配置，或通过代码设置响应头。

### 5. 如何实现 CDN 加速？

使用 Cloudflare Workers 作为 CDN，自动全球分发。
