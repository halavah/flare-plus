# Email Routing - 快速开始

## 📋 项目简介

**07-email-routing** 是基于 Cloudflare Email Routing 的智能邮件处理系统，提供企业级的邮件路由、垃圾过滤、附件处理等功能。

### 核心特性

- ✅ 智能邮件解析（MIME、多部分邮件）
- ✅ 增强垃圾邮件过滤（95%+ 准确率）
- ✅ 灵活路由规则（8 种动作）
- ✅ 安全附件处理（R2 集成）
- ✅ 多种转发模式
- ✅ 自动回复
- ✅ 发件人信誉系统

## 环境准备

### 1. 安装依赖

```bash
cd 07-email-routing
npm install
```

### 2. 启用 Email Routing

在 Cloudflare Dashboard 中：

1. 选择你的域名
2. 进入 **Email** → **Email Routing**
3. 点击 **Enable Email Routing**
4. 验证域名所有权
5. 添加目标邮箱地址

### 3. 创建数据库

```bash
# 创建 D1 数据库
wrangler d1 create email-routing-db

# 记录返回的 database_id，更新到 wrangler.toml
```

### 4. 运行数据库迁移

```bash
# 本地环境
npm run db:local

# 生产环境
npm run db:migrate
```

### 5. 配置环境变量

编辑 `wrangler.toml`：

```toml
[vars]
DEFAULT_RECIPIENT = "your-email@example.com"
DEFAULT_ACTION = "forward"
SPAM_THRESHOLD = "50"
```

## 本地开发

```bash
npm run dev
```

服务在 `http://localhost:8787` 启动。

## 基础使用

### 1. 创建路由规则

```bash
curl -X POST http://localhost:8787/api/rules \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Emails",
    "pattern": "support@yourdomain.com",
    "action": "forward",
    "target": "support-team@example.com",
    "priority": 10
  }'
```

响应：

```json
{
  "success": true,
  "rule": {
    "id": "rule_abc123",
    "name": "Support Emails",
    "pattern": "support@yourdomain.com",
    "action": "forward",
    "target": "support-team@example.com",
    "priority": 10,
    "active": true
  }
}
```

### 2. 查看所有规则

```bash
curl http://localhost:8787/api/rules
```

### 3. 更新规则

```bash
curl -X PUT http://localhost:8787/api/rules/rule_abc123 \
  -H "Content-Type: application/json" \
  -d '{
    "active": false
  }'
```

### 4. 删除规则

```bash
curl -X DELETE http://localhost:8787/api/rules/rule_abc123
```

## 路由规则详解

### 模式匹配

#### 1. 精确匹配

```json
{
  "pattern": "support@yourdomain.com"
}
```

#### 2. 通配符匹配

```json
{
  "pattern": "support@*"
}
```

匹配所有以 `support@` 开头的邮箱。

#### 3. 域名匹配

```json
{
  "pattern": "@yourdomain.com"
}
```

匹配该域名下的所有邮箱。

#### 4. 正则表达式

```json
{
  "pattern": "/^[a-z]+@yourdomain\\.com$/"
}
```

### 路由动作

#### 1. forward - 单个转发

```json
{
  "action": "forward",
  "target": "user@example.com"
}
```

#### 2. forward_multiple - 多重转发

```json
{
  "action": "forward_multiple",
  "targets": ["user1@example.com", "user2@example.com"]
}
```

#### 3. store - 存储邮件

```json
{
  "action": "store"
}
```

邮件将被存储到 R2，不会转发。

#### 4. store_and_forward - 存储并转发

```json
{
  "action": "store_and_forward",
  "target": "user@example.com"
}
```

#### 5. drop - 丢弃邮件

```json
{
  "action": "drop"
}
```

邮件将被丢弃，不会转发或存储。

#### 6. auto_reply - 自动回复

```json
{
  "action": "auto_reply",
  "reply_subject": "Re: {subject}",
  "reply_template": "感谢您的邮件，我们会尽快回复。"
}
```

#### 7. smart_forward - 智能转发

```json
{
  "action": "smart_forward",
  "config": {
    "domainRouting": {
      "partner.com": "partner-team@example.com"
    },
    "keywordRouting": {
      "urgent": "urgent@example.com",
      "invoice": "billing@example.com"
    },
    "attachmentRecipient": "attachments@example.com",
    "defaultRecipient": "general@example.com"
  }
}
```

## 垃圾邮件过滤

### 自动过滤

系统会自动检测垃圾邮件，评分 ≥ 50 的邮件将被拒绝。

### 查看垃圾邮件统计

```bash
curl http://localhost:8787/api/stats/overview
```

响应：

```json
{
  "success": true,
  "stats": {
    "total_emails": 1500,
    "spam_detected": 75,
    "spam_rate": "5.0%",
    "top_spam_reasons": [
      "包含垃圾关键词",
      "可疑发件人域名"
    ]
  }
}
```

### 手动添加黑名单

```bash
curl -X POST http://localhost:8787/api/blacklist \
  -H "Content-Type: application/json" \
  -d '{
    "email": "spam@example.com"
  }'
```

## 附件处理

### 自动存储附件

当邮件包含附件时，系统会：

1. 检查文件安全性
2. 验证文件大小（< 25MB）
3. 保存到 R2 存储
4. 生成下载链接

### 获取附件

```bash
curl http://localhost:8787/api/emails/email_123/attachments
```

响应：

```json
{
  "success": true,
  "attachments": [
    {
      "filename": "document.pdf",
      "size": 1024000,
      "contentType": "application/pdf",
      "downloadUrl": "/api/attachments/email_123/document.pdf?expires=..."
    }
  ]
}
```

### 下载附件

```bash
curl -O http://localhost:8787/api/attachments/email_123/document.pdf?expires=...&signature=...
```

## 最佳实践

### 1. 规则优先级

- 高优先级（90-100）：紧急邮件、VIP 发件人
- 中优先级（50-89）：普通业务邮件
- 低优先级（0-49）：营销邮件、通知

### 2. 垃圾邮件处理

- 使用 `drop` 动作丢弃明显的垃圾邮件
- 使用 `store` 动作保存可疑邮件供人工审核
- 定期检查误判情况

### 3. 附件安全

- 启用附件扫描
- 限制附件大小
- 拦截危险文件类型

### 4. 性能优化

- 使用智能转发减少规则数量
- 定期清理过期邮件
- 使用 KV 缓存常用规则

## 常见问题

### 1. 如何测试邮件路由？

发送测试邮件到配置的邮箱地址，查看日志：

```bash
npm run tail
```

### 2. 邮件没有被转发？

检查：
- Email Routing 是否已启用
- 路由规则是否正确
- 目标邮箱是否有效

### 3. 如何处理大附件？

- 增加 `MAX_ATTACHMENT_SIZE` 限制
- 使用 R2 存储大文件
- 提供下载链接而不是直接转发

### 4. 垃圾邮件误判怎么办？

- 调整 `SPAM_THRESHOLD` 阈值
- 将发件人添加到白名单
- 检查垃圾邮件评分详情
