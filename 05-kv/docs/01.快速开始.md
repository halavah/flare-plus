# KV 存储 - 快速开始

## 📋 项目简介

**05-kv** 是 Cloudflare KV 键值存储的完整 API 实现，提供全球低延迟的键值数据存储服务。

### 核心特性

- ✅ 基础 KV 操作（Get/Put/Delete）
- ✅ 列表和搜索
- ✅ 元数据管理
- ✅ 批量操作
- ✅ 会话管理
- ✅ 缓存管理
- ✅ 速率限制
- ✅ TTL 过期管理

## 环境准备

### 1. 安装依赖

```bash
cd 05-kv
npm install
```

### 2. 创建 KV 命名空间

```bash
# 创建 KV 命名空间
wrangler kv:namespace create "MY_KV"
wrangler kv:namespace create "MY_KV" --preview

# 记录返回的 ID，更新到 wrangler.toml
```

### 3. 配置 wrangler.toml

```toml
[[kv_namespaces]]
binding = "MY_KV"
id = "your_kv_namespace_id"
preview_id = "your_preview_id"
```

## 本地开发

```bash
npm run dev
```

服务在 `http://localhost:8787` 启动。

## API 使用示例

### 1. 基础操作

#### 写入数据

```bash
curl -X PUT http://localhost:8787/api/kv/user:123 \
  -H "Content-Type: application/json" \
  -d '{
    "value": "张三"
  }'
```

#### 写入带 TTL 的数据

```bash
curl -X PUT http://localhost:8787/api/kv/session:abc123 \
  -H "Content-Type: application/json" \
  -d '{
    "value": "session-data",
    "expirationTtl": 3600
  }'
```

#### 读取数据

```bash
curl http://localhost:8787/api/kv/user:123
```

#### 删除数据

```bash
curl -X DELETE http://localhost:8787/api/kv/user:123
```

### 2. 列表操作

```bash
# 列出所有键
curl http://localhost:8787/api/kv

# 按前缀过滤
curl http://localhost:8787/api/kv?prefix=user:

# 分页
curl http://localhost:8787/api/kv?limit=10&cursor=abc123
```

### 3. 元数据

#### 写入带元数据

```bash
curl -X PUT http://localhost:8787/api/kv/user:123 \
  -H "Content-Type: application/json" \
  -d '{
    "value": "张三",
    "metadata": {
      "age": 25,
      "city": "北京"
    }
  }'
```

#### 获取元数据

```bash
curl http://localhost:8787/api/kv/user:123/metadata
```

### 4. 批量操作

```bash
curl -X POST http://localhost:8787/api/kv/batch \
  -H "Content-Type: application/json" \
  -d '{
    "operations": [
      {
        "action": "put",
        "key": "user:1",
        "value": "用户1"
      },
      {
        "action": "put",
        "key": "user:2",
        "value": "用户2"
      },
      {
        "action": "delete",
        "key": "user:old"
      }
    ]
  }'
```

### 5. 会话管理

#### 创建会话

```bash
curl -X POST http://localhost:8787/api/sessions \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "123",
    "data": {
      "username": "张三",
      "role": "user"
    }
  }'
```

响应：

```json
{
  "success": true,
  "sessionId": "sess_abc123...",
  "expiresAt": "2024-01-16T10:00:00.000Z"
}
```

#### 获取会话

```bash
curl http://localhost:8787/api/sessions/sess_abc123...
```

#### 删除会话

```bash
curl -X DELETE http://localhost:8787/api/sessions/sess_abc123...
```

### 6. 缓存管理

```bash
# 设置缓存
curl -X POST http://localhost:8787/api/cache \
  -H "Content-Type: application/json" \
  -d '{
    "key": "api:users",
    "value": {...},
    "ttl": 300
  }'

# 获取缓存
curl http://localhost:8787/api/cache/api:users

# 清除缓存
curl -X DELETE http://localhost:8787/api/cache/api:users
```

### 7. 速率限制

```bash
curl -X POST http://localhost:8787/api/rate-limit/check \
  -H "Content-Type: application/json" \
  -d '{
    "identifier": "user:123",
    "limit": 100,
    "window": 60
  }'
```

响应：

```json
{
  "success": true,
  "allowed": true,
  "remaining": 95,
  "resetAt": 1705395600000
}
```

## 前端集成示例

### React 缓存 Hook

```jsx
import { useState, useEffect } from 'react';

function useKVCache(key, fetcher, ttl = 300) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetchData();
  }, [key]);

  const fetchData = async () => {
    try {
      // 1. 尝试从缓存获取
      const cacheResponse = await fetch(
        `http://localhost:8787/api/cache/${key}`
      );

      if (cacheResponse.ok) {
        const cached = await cacheResponse.json();
        setData(cached.value);
        setLoading(false);
        return;
      }

      // 2. 缓存未命中，获取新数据
      const freshData = await fetcher();

      // 3. 写入缓存
      await fetch('http://localhost:8787/api/cache', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          key,
          value: freshData,
          ttl
        })
      });

      setData(freshData);
    } catch (error) {
      console.error('获取数据失败:', error);
    } finally {
      setLoading(false);
    }
  };

  return { data, loading, refresh: fetchData };
}

// 使用示例
function UserProfile({ userId }) {
  const { data, loading } = useKVCache(
    `user:${userId}`,
    () => fetch(`/api/users/${userId}`).then(r => r.json()),
    600 // 10 分钟缓存
  );

  if (loading) return <div>加载中...</div>;

  return <div>{data.name}</div>;
}
```

### 速率限制组件

```jsx
function RateLimitedButton({ onClick, identifier }) {
  const [limited, setLimited] = useState(false);
  const [remaining, setRemaining] = useState(null);

  const handleClick = async () => {
    // 检查速率限制
    const response = await fetch(
      'http://localhost:8787/api/rate-limit/check',
      {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          identifier,
          limit: 10,
          window: 60
        })
      }
    );

    const result = await response.json();

    if (result.allowed) {
      setRemaining(result.remaining);
      onClick();
    } else {
      setLimited(true);
      setTimeout(() => setLimited(false), 5000);
    }
  };

  return (
    <div>
      <button onClick={handleClick} disabled={limited}>
        {limited ? '请稍后再试' : '提交'}
      </button>
      {remaining !== null && <p>剩余次数: {remaining}</p>}
    </div>
  );
}
```

## KV 最佳实践

### 1. 使用合理的键命名

```javascript
// ✅ 好 - 使用命名空间
'user:123'
'session:abc123'
'cache:api:users'

// ❌ 差 - 无结构
'123'
'abc123'
'users'
```

### 2. 设置合理的 TTL

```javascript
// 会话：1 小时
expirationTtl: 3600

// 缓存：5-15 分钟
expirationTtl: 300

// 临时数据：几秒钟
expirationTtl: 10
```

### 3. 使用元数据

```javascript
await env.MY_KV.put('user:123', 'value', {
  metadata: {
    created: Date.now(),
    version: '1.0',
    type: 'user'
  }
});
```

## 常见问题

### 1. KV 适合什么场景？

- 会话存储
- API 响应缓存
- 速率限制
- 配置数据
- 计数器

### 2. KV 不适合什么场景？

- 需要复杂查询
- 需要事务
- 频繁更新（每秒多次）
- 需要列表所有键

### 3. 免费额度

- 命名空间：100 个
- 存储：1 GB
- 读取：10 万次/天
- 写入：1000 次/天

### 4. 数据一致性

KV 是最终一致性，全球复制需要 60 秒。
